## 两个自己给自己出的考题

### Benchmark-1 · 跨过 200 步的奖励记忆

一条最简单的神经通路：信号进来，200 个时间步之后奖励才到。
网络能不能把「迟到这么久的奖励」正确归因给当初的动作？
这是强化学习里最刁钻的问题之一——**延迟信用分配**。

- C 语言核心，脉冲神经网络，资格迹 + 奖励调制三因子学习
- 10 个随机种子重复实验 + 消融对照（关掉资格迹再跑一遍）+ 延迟扫描 + 跨实现校验
- **结果：D=200 延迟下 10/10 种子 100% 正确，去掉资格迹掉到 0%（−100pp），半衰点 D½=1000 ticks**——网络真的学会了「记账」
- 判据 v1.20（2026-11-14）判为通过。边界如实保留：通过建立在放宽后的「等价口径 E1–E5」上，原字面口径下 STDP 核与 Rust `neuromod` 仍结构性不等价；`σ=4.0` 内在探索噪声是关键组件，阈值零改动

### Benchmark-2 · 教一条虚拟机械臂去够目标

两节手臂、两个关节，2256 个模拟神经元靠发放脉冲控制它们转动，
目标是把末端送到指定位置。没有反向传播，没有梯度下降，
只有「靠近了给甜头、远离了扣分」的原始奖励。

- 数百次实验、60000+ 个训练回合、800 个 CSV + 414 个 JSONL 日志文件
- 做过全面「体检」：找到并修掉了真实的内存越界 bug
- 31 项自动化测试守护工程质量（当前基线 26/31 通过，5 项为既有失败：B2 CSV 结构/字段、B1 500trials、长跑两项目；非新增回归）
- **进展**：修好 e-prop 三处实现缺陷后跨过门槛——末端距离 medD 0.2181（9/10 达标），但主判据 medR 只到 5/10（结构可塑修复后 6/10），要求 8/10；判据 v1.45 已判「不通过、结案」。调参/编码/拓扑/解码/隐藏层/结构可塑/工作点/ALIF（v1.47）/E-I 两轮（v1.48–1.49）/fan-EMA（v1.50）/破奇异起点（v1.51）共十一类杠杆均已实跑排除；可达域审计（11-21）发现 |t|<0.5 近原点目标训练+eval 95 个全部 0% 到达、物理不可达仅 1/200=任务结构性困难；startpose 课题进一步证明换起点也学不会折叠（H10 反驳）。剩余：课程学习（HER、RFCL）/ 改运动学本体（限位、臂长）/ 改任务规模，成本最高，均需新预注册

## 快速上手

需要一台 Windows 电脑 + GCC/G++ 工具链（如 MinGW-w64）+ Python 3。

```powershell
# 一键构建（生成 benchmark1.exe / benchmark2.exe / b2_core.dll）
powershell -ExecutionPolicy Bypass -File build.ps1

# 跑 Benchmark-2：50 个回合、每回合 500 步
cd Experiment
.\benchmark2.exe --episodes 50 --ticks 500 --seed 42 --out data_b2\my_run.csv

# 跑 Benchmark-1：500 个试验
.\benchmark1.exe --trials 500 --seed 7 --out data\my_b1.csv

# 自动化回归测试（31 项，基线 26/31 通过）
py audit\test_suite.py
```

`benchmark2.exe` 还支持一组实验开关（默认值与最初版本完全一致）：

```
--preset legacy|fix1|fix2|fix3      # 三级修复预设（fix1 = 单 winner 解码，实测有效）
--psp F --wta-k K                   # 突触电流增益 / WTA winner 数
--decode-mode wta|weighted          # 运动层解码方式
--reward-mode combo1|potential      # 奖励信号组合
--no-reward-baseline --tau-trace F --trace-clamp F   # 学习超参
--disable_trace --disable_reward    # 消融对照
```

每次运行都会在输出 CSV 旁生成 `<同名>.meta.json`，记录全部超参与构建信息，保证实验可复现。
