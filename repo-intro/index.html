仓库里有什么

两个自己给自己出的考题

核心是 Experiment 目录：C 语言写的「大脑」，C++ 写的实验台， Python 画的可视化，还有上百个实验留下的数据文件。

Benchmark-1

跨过 200 步的奖励记忆

一条最简单的神经通路：信号进来，200 个时间步之后奖励才到。网络能不能把「迟到这么久的奖励」正确归因给当初的动作？这是强化学习里最刁钻的问题之一——延迟信用分配。

  • C 语言核心，脉冲神经网络，资格迹 + 奖励调制三因子学习
  • 30 个随机种子重复实验 + 消融对照（关掉奖励再跑一遍）
  • 附带 Python 可视化，能看着脉冲在突触上流动
结果：30 个种子全部 100% 通过——网络真的学会了「记账」。
Benchmark-2

教一条虚拟机械臂去够目标

两节手臂、两个关节，2256 个模拟神经元靠发放脉冲控制它们转动，目标是把末端送到指定位置。没有反向传播，没有梯度下降，只有「靠近了给甜头、远离了扣分」的原始奖励。

  • 104 次实验、60000+ 个训练回合、142 个数据文件
  • 做过全面「体检」：找到并修掉了真实的内存越界 bug
  • 31 项自动化测试守护工程质量
进展：长训练下机械臂第一次真的够到了目标——虽然还不稳定。探索仍在继续。

这段旅程

从「随便玩玩」到一本正经

一开始只是想看看代码里的「神经元」长什么样。结果一玩就停不下来了。

起点 · 好奇

「大脑能不能被简化到一段代码里？」

最初的念头很朴素：真实大脑是一堆神经元互相发信号，那我能不能让一团模拟神经元自己学会完成任务？带着这个问题找到了 AI。

第一步 · 搭建

AI 把想法变成了 C 语言

我描述想要什么，AI 写代码、我跑实验、看数据、再提要求。第一版 Benchmark-1 很快跑通，30 个随机种子全部通过——那一瞬间真的会很兴奋。

升级 · 出考题

给「大脑」装一条机械臂

Benchmark-2 更野心：让 2256 个神经元通过脉冲控制两节机械臂去够目标。这一玩就是104 次实验、六万多个训练回合，数据文件铺满了目录。

体检 · 认真起来

给整个项目做了一次全面检测

让 AI 对代码、构建、数据做全面体检——还真查出了真实的内存越界 bug，复现了崩溃，然后逐项修复：突触容量、参数校验、构建脚本、31 项自动化测试。

此刻 · 仍在路上

机械臂第一次够到了目标

调整解码方式并延长训练后，机械臂末端距离第一次降到 0.074（达标线是 0.141）——虽然 100 次里只成功 1 次，但那一下，整团神经元是真的「懂了」。探索还在继续。
