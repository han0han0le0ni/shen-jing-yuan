### 实验结论（关键负结果，别重复踩）
- 重编译后 baseline 在默认「跑到碰到目标为止」配置下 50 ep 已达 median **0.1477 / PASS**，但每轮要跑 ~9860 tick——判据被「跑够久」稀释，不能用来衡量学习速度。A/B 一律改用**固定 1200 tick 预算**（150 ep，seed 12345）。

## 晚间：修 GPU 后端「机械臂乱走」（可视化侧，与上面 C 核心实验无关）

用户反馈切到 CUDA 设备时机械臂容易乱走。勘察后确认是 `vis/backend_vec.py` 与 C 核心动力学不同源，不是 GPU 数值误差。

### 根因
1. 输入层编码的是**目标绝对坐标**，而 C 核心编码 `target - end` 相对位置 + `PROP_N=56` 个本体感觉神经元（θ1/θ2/ψ1/ψ2 环形角）。GPU 后端完全开环，网络不知道手臂在哪，只会沿一个固定方向转。
2. 缺 C 核心的 **INPUT→MOTOR 直连**（K=12，权重 1.5~2.5），感知信息只能经弱 H→M 通路抵达运动层。
3. 解码用「最近 5 tick 活跃神经元 + 正负池分离投票」，把不同 tick、不同方向的 winner 混在一起；C 核心是「本 tick WTA winner 的 pref_omega 均值」。
4. CUDA `trace_update` kernel 硬编码资格迹 ±5，numpy 路径用 `hp["trace_clamp"]=1.0` → 两条路径训练后分叉（实测 numpy 末距 2.891 / CUDA 1.019）。WTA tie-break 也不同（串行 `>` vs `xp.partition`）。
5. `pref_omega` 范围 [-1,1] 而 C 是 [-0.5,0.5]；`ENCODE_SIGMA_POS` 0.85 而 C 是 2.0。
6. 观感层：worker 每轮跑 `_steps` 步却只取 1 帧，主线程每帧只画 1 个轨迹点，25× 速度下折线像瞬移。

## 深夜：修「一级关节卡死、二级关节在目标周围转圈，不靠近目标」（v7 目标引导）

### 根因（不是 v6 的 GPU/后端分叉，是三后端共有的控制层问题）
- 诊断结果：θ1 只在 [-0.05,+0.04]（numpy 后端 -0.27~0）摆动，θ2 只在 [-0.02,+0.19] 摆动；末端包围盒 x[1.98,2.00] y[-0.10,0.22]，末端半径恒定 1.998；dist 1.343 → 1.242（numpy 甚至涨到 1.492），**0 次到达**。
- 本质：k-WTA 解码出的 ω 是**零均值高频抖动**（|ω|≈0.138 但净位移为零），没有朝目标的直流分量。INPUT→MOTOR 直连权重全随机、奖励 combo1 在纯振荡下正负交替且被 200 tick 基线减掉，R-STDP 学不到方向映射。网络知道自己在哪，却不知道该往哪转。
- 次要问题：`arm_step` 把 θ1 **硬钳在 ±π**，一旦顶边界就是吸收态，末端自由度只剩 θ2，只能在以肘为圆心的单位圆上转 —— 正是用户看到的「卡死 + 绕圈」；随机目标半径下限 0.3，而 θ2 限位 ±0.9π 时末端最短可达半径 = 2cos(0.45π) ≈ 0.313，存在物理不可达区。

### 改动

- **交付：`Experiment/vis/transfer_lab.py`（唯一新增文件）**。单文件 PySide6 窗口，`sys.dont_write_bytecode=True`，不写日志/CSV/截图；实测运行后 `vis/__pycache__` 不生成。**删掉这一个文件即恢复原状**，`neuron_vis.py` / `backend_vec.py` / C 核心 / DLL 全部零改动（大小复核未变）。
- 运行 `py -3 Experiment/vis/transfer_lab.py`，自检 `... --check --ticks 20000`。参数 `--readout-lr / --wta-k / --dagger-every / --probe-every / --teacher / --seed`。
- 界面：G 大字 + 引导/自主占比、G 退火曲线、g=0 探针（到达率/方向余弦）曲线、8 张指标卡（含**探针口径**的方向余弦与自主/教师速度比）、机械臂轨迹、一键「强制纯自主 G=0」、「立即评估」、重置。状态栏写明独立可删与验收标准。
- **验收判据（唯一口径）**：g=0 探针 = 3 个固定目标 × 800 tick，隔离后端（只覆盖 `Wt/W/readout_w` 快照、`reward_mod=0`）；「已自主」= G≤0.02 且连续 3 次探针 ≥2/3 到达。带引导到达次数不算能力。

### 三轮实验的结论（别再走回头路）
1. **纯 R-STDP 分通道教师**（有符号奖励按 post 所属运动层施加到资格迹）：6000 tick 后 cos 仍 −0.04，g=0 探针 0/3、最小距离反而 1.338。资格迹只有时序、无输入状态门控，同一突触在不同目标下被反复强化又削弱 → 无效甚至有害。保留为 `--teacher` 对照开关，默认关。
2. **`pref_omega` 可塑（delta rule 只改本 tick winner）**：方向 cos 能到 +0.85，但**幅度塌缩**（自主/教师速度比 0.39→0.19）。诊断：winner 状态分化其实很好（50 个都当过、状态间 Jaccard 0.042），问题是 50 个神经元级标量无法表达连续状态→输出映射，pref 全部收敛到同一小值（std 仅 0.03、均值 −0.13）。降 wta_k(1/2/3)、满幅方向目标都救不了。
3. **可塑线性群体读出（最终方案）**：override `_decode_omega`，以 `is_spiking[:m1_start]`（输入层+隐层脉冲）为特征、两关节各一组权重，NLMS `w += lr*(t-p)*x/(n+1)` 在线回归教师方向（保留关节比例、幅度归一满速）。特征随状态变化 → 状态门控，推理期输出完全由网络活动产生。**速度比 0.89→1.23 不再塌缩**，G 0.7→0.24，探针两次 1/3 到达、最小距离 0.145。
- 另加：DAgger（每 2 轮一次 g=0 自主采样训练轮，解决训练/评估分布不匹配死锁）、缓慢时间表 `g*=0.98` 兜底（下限 0.30，突破必须靠探针）、**历史最佳权重检查点**（连续 2 次评估变差回滚 `readout_w`）、失败回退 G。
- **诚实结论：20k tick 内尚未达成可靠自主**（探针最高 1/3，会反复退化；G 停在 0.24–0.32）。所以界面把「G 课程进度」与「g=0 到达率」并列显示，阶段文字保持「训练中」，绝不显示假成功。这是**监督蒸馏解析控制器**，不是网络自己发现逆运动学。
- 坑：PySide6 `QPen` 没有 `setAlpha()`（要 `QColor.setAlpha`），写错会 paintEvent 反复抛异常并在 grab 时段错误；offscreen 仍需 `QT_QPA_FONTDIR=C:/Windows/Fonts`。
