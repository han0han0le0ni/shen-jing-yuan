# 2026-11-09

## 神经元可视化软件：定位、优化、汉化与美化

- **定位**：工作区里唯一「看神经元」的软件是 `Experiment/vis/neuron_vis.py`（PySide6 桌面 GUI）；11 个 exe 全是 benchmark/debug 命令行程序。它用 ctypes 调 `Experiment/b2_core.dll`（x64，Python 也须 64 位），数据走 topology/snapshot 两个 JSON。
- **依赖**：本机默认 Python 3.14.3，已装 PySide6 6.12.0（6.10+ 支持 3.14）。启动：`cd Experiment && python vis/neuron_vis.py`。
- **重写内容**：全中文界面；深色/浅色双主题（`THEMES` + `build_qss` + 主题按钮）；卡片式 header / 控制栏 / 双面板 / 指标卡 / 膜电位色带图例；隐藏层改多行网格排布（200 个节点不再挤成一条线）；机械臂网格改为 `drawBackground` 铺满视口。
- **修复的缺陷**：首次启动 `destroy()` 未初始化指针；每帧导出两次快照；每帧重建目标准星与 spike 图元；最大可达圆未乘缩放；视图不随窗口自适应；单步被速度倍率放大。
- **性能优化**：1399 条突触按权重合并为 4 条 QPainterPath；发放突触高亮合并为 1 条 path；所有图元预创建逐帧只改属性；膜电位颜色预生成 48 级 QBrush 查表；快照临时文件移到系统临时目录并复用；速度改用步长累加器（0.5x~10x 精确生效）；单步恒为 1 步。
- **字体**：`ensure_fonts()` + `pick_font_family()`，优先微软雅黑、回退 SimHei；字体库为空时从 `C:\Windows\Fonts` 补载，避免无头/远程会话中文变方块。装饰符号（▶ ☀ 等）全部移除，统一纯中文。
- **快捷键**：空格 运行/暂停、S 单步、R 重置、T 随机目标。
- **产物**：原版备份 `vis/neuron_vis_原版备份.py.bak`；预览图 `vis/preview_dark.png`、`vis/preview_light.png`。
- **验证**：`QT_QPA_PLATFORM=offscreen` 冒烟测试通过（172 步仿真、双主题切换、单步/播放/暂停/重置、字体加载），语法编译通过。
