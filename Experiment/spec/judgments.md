# 验收判据 · 冻结 v1（2026-11-12）

> 依据：设计定稿 §12；本文件一经冻结，修改必须记录版本、理由与影响范围。
> **未通过 Benchmark-1 之前，不得启动 Benchmark-2 以上开发。**

## 0. 全局口径（先于一切判据）

1. **能力口径**：衡量网络能力只允许用 `g=0`（无任何教师/解析公式）的到达率与平均到达步数。`g>0` 的到达次数不计入能力。
2. **中位数**：标准定义（排序后 `n` 为奇数取中项，偶数取中间两项均值）。禁止 `ratios[n/2]` 上中位数。
3. **固定预算**：所有 A/B 必须固定 tick 预算（默认 1200 tick/ep），同时报告到达率与平均到达步数；「跑到碰到目标为止」只用于演示，不作判据。
4. **分母保护**：`init_dist` 下限 0.10；低于下限的 episode 标记 `invalid` 并从统计剔除。主指标优先用绝对末端距离。
5. **独立脑实例**：每个 benchmark、每个消融条件使用独立检查点目录与 `seed_bundle`，不继承结构。
6. **单变量**：一次只改一项；报告 median + 种子分布，不堆叠优化后归因。
7. **禁止伪造奖励**：外部评分失败时丢弃本次奖励，不更新基线；连续 5 次失败 → 降级内部误差；仍不可用 → 冻结学习。禁止用 `R_base` 顶替。

## 1. Benchmark-1（单突触远端信用分配）

**任务**：500–2000 神经元；t=0 给刺激 A/B，延迟 D 后给奖励/惩罚；下一试次调整输出偏好。

**判据**

| 项 | 阈值 |
|---|---|
| D=200 正确率 | ≥ 80% |
| 资格迹消融（无迹） | 相对完整组下降 ≥ 30 个百分点 |
| 半衰点 D½ | ≥ 200 ticks |
| 延迟扫描 | D ∈ {10, 50, 100, 200, 500, 1000} 全覆盖 |

**强制报告**
- 延迟-正确率曲线；
- 多尺度（K=2–3）vs 单尺度消融；
- τe–N 曲线（N=500/1000/2000），拟合指数；偏离 0.5 则修正标度律并重跑；
- 与 `neuromod`（Rust）同种子的统计等价（均值/方差/迹曲线；**不要求 1e-4 逐位一致**）；
- 稀疏化：无迹组权重 Gini / 有效连接数是否停在随机初始化水平。

**失败动作**：停止，转 T1/T2 研究（前向模型、解码可学性），不得进入 B2。

## 2. Benchmark-2（两关节虚拟臂到达）

**规模**：5,000–20,000 神经元。

**判据**

| 项 | 阈值 |
|---|---|
| 末端距离中位数 | ≤ 初始距离 20% |
| 种子 | 10 个中至少 8 个达标 |
| 成功率 | 末距 < 4 cm 的 episode 占比单独报告 |
| 泛化 | 随机/多目标单独统计，不得只在固定目标上评估 |

**强制报告**
- 中位数 + 直方图 + 成功率（防双峰被中位数掩盖）；
- 到达率/平均到达步数（固定 1200 tick 预算）；
- 记忆半衰期与崩溃率（门控关闭后的衰减曲线）；
- 颗粒层消融、`er_eligible` 泄漏检测（非动作簇权重变化必须为 0）；
- 竞争性发生 / 稳定性通道 / 修剪判据三组消融；
- ≥5 种子（优先 10），mean ± SD，Wilcoxon signed-rank 配对检验，Cohen's d 或相对下降%。

**门槛**：M2 探针（5000 神经元、仅异构输出 + 群体解码 + 势能塑形）要求 10 seed 中 ≥6 个 median ≤ 0.40 且 g=0 到达率 > 0，才允许上结构可塑。

## 3. Benchmark-3（最小陪伴对话循环）

**规模**：20,000–50,000 神经元；固定模板集 + 10–20 个回应标签 + 离线评分表。

**判据**

| 项 | 阈值 |
|---|---|
| 1000 轮后留出集一致率 | ≥ 70% |
| 相对基线 | 显著高于「不学习固定随机策略」与「纯 STDP 无奖励调制」 |
| 校准 | ECE < 0.10（不只报熵） |
| 睡眠巩固 | 巩固前后长期记忆保持率差值 > 0 |

**强制报告**：留出集一致率、ECE、睡眠前后保持率、基元库扩展消融（固定 vs forge 提取）、双条件（A 离线评分表为准；B 小规模实时 AI 评分 100–200 轮，报告延迟与失败率）。

## 4. 跨基准强制消融（缺一不可）

每个基准都必须报告以下条件相对完整系统的变化：

1. 移除资格迹
2. 移除误差注入通道
3. 移除多通道调质（退化为单通道奖励）
4. 移除异构群体编码
5. 移除竞争性神经发生
6. 移除睡眠重放

**没有消融表，通过判据不成立。**

## 5. 统计与数据规范

- 日志只写 JSONL：`train / ablation / health / reward`；CSV 停用。
- 每次运行写 `meta.json`：源码哈希、二进制哈希、`seed_bundle` 四子种子、全部参数、判据版本。
- 报告必须给：median、mean、SD、种子级原始值；不得只给最好一次。
- 失败运行保留，不删除；`results.csv` 之类旧格式归档到 `data/legacy/`。

| 基准 | 现状 | 按本判据 |

**B1 修复记录**（详见 `.workbuddy/memory/2026-11-12.md`、`audit/b1_m1_report.md`）：

1. 奖励延迟改用全局 tick（旧实现用 trial 局部计数，200 tick 延迟从未真正生效）；
2. PSP 因子 25 → 10（25 时输出层饱和，权重变化不影响发放，学习对投票完全无效）；
3. K=1 时 alpha 归一化（旧实现沿用 1/3，信用被暗削 3 倍）；
4. hidden→output 初始化 65/35 → 50/50（去掉预埋正确映射），投票改观察窗口累计，输出层加侧抑制。

**注意**：D≤200 时多尺度与单尺度无差异（任务太容易），多尺度价值只在 D=500 体现（+20.6pp）。D=1000 两者都失效。不得据此宣称「多尺度全面占优」。

### 6.2 根因诊断与四流契约（2026-11-12 深夜 · T1/T2 第一步）

> 依据：`audit/b1_root_cause_2026-11-12.md`、`data/b1_bias/diagnosis_summary.jsonl`（54 次独立进程实跑，可复算）。
> 本节只更新**现状与工程事实**，不修改任何判据阈值；未改学习规则、刺激生成器或任务定义。

**M0 `seed_bundle` 四流已落到 B1 运行时**：`brain/benchmark1_core.c` 用 structure / weight / noise 三条独立流替换旧单流 `g_rand_state`；`host/benchmark1_host.cpp` 用同一 master seed 派生的 trial_order 流生成刺激序列。新增 `--structure-seed / --weight-seed / --noise-seed / --trial-order-seed` 单变量覆盖与 `--legacy-rng`（逐位复现旧行为）。新增只读诊断 `net_output_bias()`：统计 hidden 左/右半 → 输出 A/B 四类权重和，导出 `beta`（正确映射净偏向）与 `delta_out`（输出侧绝对偏向）。

| 诊断项 | 实测 | 含义 |
|---|---|---|
| 只换 trial_order 流（8 值，结构/权重固定） | 8/8 全部 100.00%，SD = 0.00 | 刺激顺序对结果零影响 |
| 只换 weight 流（8 值） | 0–100%，SD 44.45，2/8 达标 | 初始权重主导 |
| 只换 structure 流（8 值） | 0–100%，SD 37.87，2/8 达标 | 初始拓扑主导 |
| 10 seed · 新四流 | mean 37.53%，2/10 达标 | 仍 FAIL |
| 10 seed · 旧单流 | mean 21.87% / median 5.00% / 1/10 | 与 §6.1 完全一致，证据链闭合 |
| 44 次有学习运行的 beta 变化绝对值 | 平均 0.0013 | 学习几乎未改变净映射 |
| 10 对「完整 − 无迹」 | 平均 −3.53pp，8/10 完全相同 | 消融判据不成立 |

**结论**：B1 当前任务测到的是「初始随机网络实例是否落在输出层竞争的可分辨工作点」，不是远端信用分配。判据**仍不通过**；按 §1 失败动作继续停在 T1/T2，不得进入 B2。

**对重做 B1 的约束（实验设计要求，非阈值变更）**：① 初始输出读出必须严格对称，消除初始答案；② 正确率提升必须能用配对消融归因到学习；③ 所有 A/B 按 §0.6 单变量并用四流覆盖开关隔离；④ 先做离线监督上界确认架构表达力，再谈局部学习规则。禁止通过调 lr / psp / τ 或改刺激生成器去「刷过」判据。

### 6.3 离线监督上界（2026-11-12 深夜 · T2 第一步）

> 依据：`audit/b1_supervised_ceiling_2026-11-12.md`、`data/b1_ceiling/ceiling_summary.jsonl`（10 seed × 200 试次，可复算）。
> 本节只记录**现状与研究结论**，不修改任何判据阈值；未改学习规则、刺激生成器、任务定义或 host。

**实现约束**：新增 `brain/benchmark1_probe.c` 只读适配层，链接既有 `b1_core.o` 生成 `b1_probe.dll`；`benchmark1_core.c/h` **一行未改**（SHA1 与 §6.2 报告一致），根因诊断证据链不断。诊断期间全程不注入奖励，权重 checksum 前后差为 0，自证零学习。

| 项 | 实测 | 含义 |
|---|---|---|
| 离线监督上界（5 折 CV 岭回归读出） | **10/10 seed 全部 100.00%**，mean 100.00%，SD 0.00 | hidden 表示线性可分 |
| 标签 shuffle 对照 | mean 49.10% | 上界不是 CV 泄漏 |
| 500 个随机线性读出 | mean 50.44% | 未训练的读出在机会水平 |
| B1 冻结权重初始投票 | 0 / 50 / 100 三值，mean 40.00% | 初始答案由随机实例决定 |
| 初始投票 vs 训练后 test_acc（同四流 RNG，配对 10 seed） | **corr 0.9818**，平均绝对差 4.20pp，6/10 完全相同 | **训练几乎没有改变答案** |
| 同配对但换旧单流 RNG | corr 0.5467，平均绝对差 29.20pp | 高相关来自同一实例，非数值巧合 |
| 特征确定性 | 每 seed 仅 2 种模式，类内方差 0 | 「可分」是**平凡可分**，不可解读为网络学到了东西 |

**结论**：B1 的架构表达力**不是瓶颈** —— 刺激 A/B 的信息确实进入 hidden 层，一个线性读出即可完全分开；失效点在 **初始 hidden→output 读出的随机不对称 + 侧抑制放大 + 局部学习规则改不动净映射**。§6.2 的重做顺序由此获得上界支撑：先做约束 ①（初始读出严格对称，消除初始答案），再用配对消融归因（②），全程单变量四流隔离（③），最后才谈 T1 局部学习规则 / 前向模型。

**诚实边界**：上界由外部监督解直接读取标签求得，网络本身没有标签；**这不构成 B1 通过**。禁止据此调 lr / psp / τ 或改刺激生成器去「刷过」判据。判据状态不变：B1 仍不通过；按 §1 失败动作继续停在 T1/T2，不进 B2、不写容器、不写 SNC。
