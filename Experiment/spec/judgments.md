# 验收判据 · 冻结 v1（2026-11-12）

> 依据：设计定稿 §12；本文件一经冻结，修改必须记录版本、理由与影响范围。
> **未通过 Benchmark-1 之前，不得启动 Benchmark-2 以上开发。**

## 0. 全局口径（先于一切判据）

1. **能力口径**：衡量网络能力只允许用 `g=0`（无任何教师/解析公式）的到达率与平均到达步数。`g>0` 的到达次数不计入能力。
2. **中位数**：标准定义（排序后 `n` 为奇数取中项，偶数取中间两项均值）。禁止 `ratios[n/2]` 上中位数。
3. **固定预算**：所有 A/B 必须固定 tick 预算（默认 1200 tick/ep），同时报告到达率与平均到达步数；「跑到碰到目标为止」只用于演示，不作判据。
4. **分母保护**：`init_dist` 下限 0.10；低于下限的 episode 标记 `invalid` 并从统计剔除。主指标优先用绝对末端距离。
5. **独立脑实例**：每个 benchmark、每个消融条件使用独立检查点目录与 `seed_bundle`，不继承结构。
6. **单变量**：一次只改一项；报告 median + 种子分布，不堆叠优化后归因。
7. **禁止伪造奖励**：外部评分失败时丢弃本次奖励，不更新基线；连续 5 次失败 → 降级内部误差；仍不可用 → 冻结学习。禁止用 `R_base` 顶替。

## 1. Benchmark-1（单突触远端信用分配）

**任务**：500–2000 神经元；t=0 给刺激 A/B，延迟 D 后给奖励/惩罚；下一试次调整输出偏好。

**判据**

| 项 | 阈值 |
|---|---|
| D=200 正确率 | ≥ 80% |
| 资格迹消融（无迹） | 相对完整组下降 ≥ 30 个百分点 |
| 半衰点 D½ | ≥ 200 ticks |
| 延迟扫描 | D ∈ {10, 50, 100, 200, 500, 1000} 全覆盖 |

**强制报告**
- 延迟-正确率曲线；
- 多尺度（K=2–3）vs 单尺度消融；
- τe–N 曲线（N=500/1000/2000），拟合指数；偏离 0.5 则修正标度律并重跑；
- 与 `neuromod`（Rust）同种子的统计等价（均值/方差/迹曲线；**不要求 1e-4 逐位一致**）；
- 稀疏化：无迹组权重 Gini / 有效连接数是否停在随机初始化水平。

**失败动作**：停止，转 T1/T2 研究（前向模型、解码可学性），不得进入 B2。

## 2. Benchmark-2（两关节虚拟臂到达）

**规模**：5,000–20,000 神经元。

**判据**

| 项 | 阈值 |
|---|---|
| 末端距离中位数 | ≤ 初始距离 20% |
| 种子 | 10 个中至少 8 个达标 |
| 成功率 | 末距 < 4 cm 的 episode 占比单独报告 |
| 泛化 | 随机/多目标单独统计，不得只在固定目标上评估 |

**强制报告**
- 中位数 + 直方图 + 成功率（防双峰被中位数掩盖）；
- 到达率/平均到达步数（固定 1200 tick 预算）；
- 记忆半衰期与崩溃率（门控关闭后的衰减曲线）；
- 颗粒层消融、`er_eligible` 泄漏检测（非动作簇权重变化必须为 0）；
- 竞争性发生 / 稳定性通道 / 修剪判据三组消融；
- ≥5 种子（优先 10），mean ± SD，Wilcoxon signed-rank 配对检验，Cohen's d 或相对下降%。

**门槛**：M2 探针（5000 神经元、仅异构输出 + 群体解码 + 势能塑形）要求 10 seed 中 ≥6 个 median ≤ 0.40 且 g=0 到达率 > 0，才允许上结构可塑。

## 3. Benchmark-3（最小陪伴对话循环）

**规模**：20,000–50,000 神经元；固定模板集 + 10–20 个回应标签 + 离线评分表。

**判据**

| 项 | 阈值 |
|---|---|
| 1000 轮后留出集一致率 | ≥ 70% |
| 相对基线 | 显著高于「不学习固定随机策略」与「纯 STDP 无奖励调制」 |
| 校准 | ECE < 0.10（不只报熵） |
| 睡眠巩固 | 巩固前后长期记忆保持率差值 > 0 |

**强制报告**：留出集一致率、ECE、睡眠前后保持率、基元库扩展消融（固定 vs forge 提取）、双条件（A 离线评分表为准；B 小规模实时 AI 评分 100–200 轮，报告延迟与失败率）。

## 4. 跨基准强制消融（缺一不可）

每个基准都必须报告以下条件相对完整系统的变化：

1. 移除资格迹
2. 移除误差注入通道
3. 移除多通道调质（退化为单通道奖励）
4. 移除异构群体编码
5. 移除竞争性神经发生
6. 移除睡眠重放

**没有消融表，通过判据不成立。**

> 本节只记录**现状与研究结论**，不修改任何判据阈值；学习规则、刺激生成器、奖励规则、host 一律零改动。

**实现**：新增 `brain/benchmark1_sym.c` → `b1_sym.dll`，只链接既有 `b1_core.o` / `seed_bundle.o`；只重建 `hidden→output` 一段，把 m 条边两两配对成 `(pre_k→OA_j, w_k)` 与 `(pre_k→OB_j, w_k)`，插值剂量 `w=(1−α)·w_orig+α·w_k`。`α=0` 逐位恢复原始网络，`α=1` 严格对称。`benchmark1_core.c/.h`、`benchmark1_probe.c` SHA1 与 §6.2/§6.3 报告一致，证据链不断。试次协议复刻 host（观察 15 / 刺激 10 / D=200 / 冷却 30，lr 0.02、psp 10、trace_k 3）。

**与计划措辞的偏差（如实记录）**：§6.3 / 附录 D.4 写「让冻结正确率回到机会水平（50%）」，实测是 **0% 正确 / 100% 平局**：host 把平局计为错误且不给奖励，而严格对称必然让两侧发放数相等。这比机会水平更彻底地消除了初始答案，但暴露出更根本的死锁。

**新根因（比 §6.2 更进一层）**：B1 的学习信号完全依赖初始不对称产生的「有对有错」；严格对称 → 平局 → `reward=0` → 零更新 → 永远平局。探索组进一步证明：即使人为注入非零奖励，镜像边因「同一前神经元活动 → 相同资格迹 → 相同奖励调制」被等量更新，对称仍不破缺。与 §6.3「架构表达力 10/10 线性可分」合起来，瓶颈定位在**读出与信用分配的耦合**，不是表示能力或超参数。

**约束状态**：① 严格对称 **已完成**；② 同 seed 配对消融 **已完成（负结果）**；③ 单变量四流隔离 **已完成**。**B1 仍不通过**，按 §1 失败动作继续停在 T1/T2，不进 B2、不写容器、不写 SNC。

**下一步（T1，仍未做）**：必须同时满足两个条件才可能学到东西 —— ① 奖励/教学信号**与刺激相关**；② 存在**对称破缺机制**（状态相关探索、内部前向模型或异质化读出）。在严格对称基线上重做配对消融；**禁止靠调 lr / psp / τ 或改刺激生成器刷过判据**。探索性硬币组不计入任何验收。
