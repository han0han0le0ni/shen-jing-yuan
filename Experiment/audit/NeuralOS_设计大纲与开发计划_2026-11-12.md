## 1. 设计大纲

### 1.1 系统定位

自组织、可生长、可自愈、无向量依赖的脉冲型数字神经系统，作为通用神经操作系统研究平台。非目标：大模型、反向传播、向量数据库、Transformer。

### 1.2 四条原则与可检查项

| 原则 | 工程含义 | 可自动检查 | 当前状态 |
|---|---|---|---|
| 无反向传播 | 权重只由局部规则（STDP/资格迹/调质）更新，全局不出现梯度反传 | 静态扫描：核心代码无 autograd / 无全局误差回传路径 | 满足（C 核心为局部规则）；但 Python 侧若引入 PyTorch 框架则破坏 |
| 无向量相似度 | 不维护全局嵌入，不做余弦/最近邻检索 | 核心无 embedding 表、无 ANN 索引 | 满足；注意「脉冲时序相关性 ρ」本质仍是相似度，需在规范中写明边界 |
| 事件驱动为主 | 计算由脉冲触发；衰减用惰性时间戳批量结算 | 每 tick 遍历数 ∝ 活跃神经元/突触，而非 ∝ 全网络 | **不满足**：三后端均为逐 tick 全量数组更新 |
| 结构/权重分离演化 | 权重连续每 tick；结构离散、独立裁决 | 结构变更只发生在裁决事件，有事件日志 | **不满足**：仅有 `synapse_capacity` 预留，无裁决规则 |

### 1.3 总体架构

```
┌──────────────────────── Body（宿主，无权重读写权） ────────────────────────┐
│  UI(ImGui 或 PySide6) │ 调度器 │ 资源管理 │ 外部AI(HTTP) │ 沙箱 │ Body-SNC │
└───────────────▲──────────────────────────────┬────────────────────────────┘
                │ BRAIN.OUT.PROPOSE / HEALTH   │ BRAIN.IN / IN.EXECUTE / IN.MODULATION
                │ / caps                       │ / SLEEP / REPAIR / quota
┌───────────────┴──────────────────────────────▼────────────────────────────┐
│                        Link（契约层：schema + 权限 + 版本）                 │
├───────────────────────────────────────────────────────────────────────────┤
│  Brain（纯 C 核心）                                                        │
│  神经簇(S/O/A/N/P/M/D/E/G/PDc/PPm/GIn) │ 突触(w,e,p,flags) │ 调制 │ 解码   │
│  基元链 │ 记忆(痕迹槽/补全/重放) │ Brain-SNC(分化/裁决/修剪/回收/睡眠)      │
│  容器层(.neuro mmap 热数据 / Zstd 冷数据 / 检查点 / .delta)                 │
└───────────────────────────────────────────────────────────────────────────┘
```

### 1.4 端口契约（实现时必须先定 schema）

| 端口 | 方向 | 载荷 | 关键约束 |
|---|---|---|---|
| `BRAIN.IN` | Body→Brain | 刺激包：`{modality, tensor_ref, t}` | 不携带奖励，不改权重 |
| `BRAIN.IN.EXECUTE` | Body→Brain | `{intent_id}` | 睡眠中返回 `E_SLEEPING` |
| `BRAIN.IN.MODULATION` | Body→Brain | `{m_Rw, m_Ac, m_Er[], t}` | 只写调质，不直接改权重；失败不得伪造 |
| `BRAIN.OUT.PROPOSE` | Brain→Body | `{type,label,confidence,posterior}` | 不含完整内容 |
| `BRAIN.HEALTH` | Brain→Body | `{struct_ok, weight_overflow, trace_anomaly}` | 每 1000 ticks |
| `BRAIN.REPAIR` | Body→Brain | `{checkpoint_id}` | 不回滚资格迹矩阵（需补充一致性规则） |
| `BRAIN.SLEEP` | Body→Brain | `{mode, budget}` | 输入进有界 FIFO |
| `caps` / `quota` | 双向 | 能力声明 / 配额 | 启动时校验 |

**建议**：端口用 FlatBuffers 定义 `.fbs`，生成 C 头 + Python 绑定，避免手写序列化。

### 1.5 核心数据结构草案（C）

```c
/* 热路径神经元标识：不用字符串 */
typedef struct {          /* 8 + 4 + 4 + 4 + 4 = 24 B，可对齐到 24/32 */
    uint64_t id_hash;     /* FNV-1a 8B */
    uint32_t type_code;   /* 'S'<<24 | 'V'<<16 | 'I'<<8 ... 4B */
    uint32_t batch, parent, indiv;   /* 三段定长索引 */
} NeuronKey;

/* 突触热数据：连续排列，e 与 p 同区块（设计 6.1） */
typedef struct {
    uint32_t pre, post;        /* 8 B，索引而非指针 */
    float    w;                /* 4 B */
    float    e[3];             /* 多尺度迹 K=3，12 B */
    uint16_t p_half;           /* 4.3 元可塑，float16 存储，更新时提升 float32 */
    uint16_t flags;            /* er_eligible / inhibitory / frozen */
} SynapseHot;                  /* 32 B/synapse，600 万突触 ≈ 192 MB */

/* LIF 精确指数解（设计 4.3） */
static inline void lif_step(LifState *s, float I, float dt, const LifParam *p) {
    float beta = expf(-dt / s->tau_m);
    s->v = beta * s->v + (1.0f - beta) * I;
    if (s->v >= p->v_th) { s->v = p->v_reset; s->refract = p->t_ref; s->spiked = 1; }
}
```

**注意**：`SynapseHot` 32 B × 600 万 = 192 MB，加上索引、神经元状态、解码器、记忆槽，50 万神经元整体落在 0.5–1.5 GB，31 GB 机器可承受。千万级需 20–40 GB，只能离线跑。

### 1.7 单 tick 执行顺序（冻结用）

```
1. 取事件队列（刺激/调质/执行指令），按时间戳排序
2. 惰性结算：对上次访问以来经过的 τ 做批量衰减（w, e, p, s_trace）
3. 神经元积分（仅活跃集合）→ 产生 spike
4. 脉冲投递：只遍历活跃神经元的出边，写一次资格迹（禁止从 last_spike_time 重复计算）
5. 调质更新：(m_Rw − R_base)、m_Ac 滤波、m_Er 投影
6. 权重更新：Δw = η·γ_brake(w)·(1/p)·[(m_Rw−R_base)Σα_k e^(k) + m_Er·e^A]
7. 结构裁决（低频，每 N tick）：修剪候选 → 生长 → 竞争 → 凋亡
8. 健康检查（每 1000 tick）、日志（JSONL）
9. 快照/提案（PROPOSE 时写意图缓冲，EXECUTE 时读意图态）
```

### 2.3 实测结论（正/负结果，避免重踩）

**正结果**

- CUDA 与 numpy 轨迹逐位一致（1500 tick 全指标相同，max|Δ|≈1e-8）；纯 tick 7216 tick/s（2200 神经元 / 19882 突触），GUI 62 FPS。
- 相对位置 + PROP + INPUT→MOTOR 直连修好了「开环乱走」：路径长度 24.16 → 9.16（C DLL 参照 9.07），包围盒 0.15 → 0.019。
- `novelty_gain=1.0`：3 个 seed median 改善 3.1% / 4.4% / 7.2%。
- θ1 周期 wrap 修好「关节卡死」：10/10 方向目标可达，θ1 跨度最大 3.41 rad。

**负结果（写进规范，禁止重复试）**

- 攀爬纤维式标量误差注入（含中心化 + PF 门控）：median 单调劣化（0.947→3.27），gain≥0.5 时 42–54% 突触触底。**缺的是可学习内部正向模型，不是注入通路。**
- k-WTA 解码下 ω 为零均值抖动，无朝目标直流分量 → 纯网络 0 到达。
- 固定引导 g=0.5 连训 12 轮：到达步数 416→404（−3%），网络/目标方向 cos 始终 ≈0。
- 引导消融：g=0→0 次到达，g=1.0→9 次/206 tick。**g>0 的到达次数不能当网络能力。**
- B1 消融组（关迹/关奖励）与完整组同为 100%，判据无区分度。

## 4. 缺少的理论与支持

### 4.1 理论缺口（按阻塞程度排序）

**T1 可学习的内部正向模型（最高优先级）**
- 问题：信用分配需要「动作 → 下一状态」的可预测关系，现有网络只有感知→动作映射，没有前向模型。
- 证据：`error_gain` 单调劣化；k-WTA 输出零均值抖动；g=0 到达 0 次；12 轮 cos≈0。
- 影响：直接决定 B2 能否通过；不解决则任何误差通道都是加噪。
- 可选解法：① 局部学习的线性/非线性预测器（RLS/Kalman，权重用局部规则更新）；② e-prop 的事件驱动近似；③ 势能塑形奖励 + 多尺度迹提高信噪比（最低成本，先试）。
- 验证：固定 seed 下，g=0 到达率随训练单调上升，且预测误差与到达率负相关。

**T2 解码层的可学性（k-WTA → PDc）**
- 问题：单 winner 解码产生的 ω 无直流分量；PDc 群体解码后能否产生稳定方向未知。
- 证据：`pref_omega` 可塑时方向 cos 能到 0.85 但幅度塌缩到 0.19；线性群体读出速度比 0.89–1.23 但到达率仅 1/3。
- 影响：B2 的第二大阻塞。
- 解法：PDc 相对发放率 + 基线扣除 + 群体向量；固定偏好向量、只学 `w_jc`；先做 5000 神经元离线监督上界，确认架构表达力。
- 验证：离线监督训练能达到 median <0.2 才说明架构可行；否则改解码或加前向模型。

**T3 多尺度资格迹的稳定性与标度律**
- 问题：K=2–3、α=1/K 起步，但混合尺度会改变有效学习率；τe ∝ √N 未经校准。
- 影响：B1 的强制报告项；若不稳，B2 无地基。
- 解法：先 K=1 建基线，再逐档加；按设计跑 N=500/1000/2000 三档测 τe，拟合指数，偏离 0.5 则修正式。
- 验证：同一 seed 下迹曲线可复现；消融下降 ≥30pp。

**T4 结构可塑的收敛性**
- 问题：竞争性发生 + 修剪 + 稳定性竞争三者叠加，缺少收敛/震荡分析；500 tick 贡献滑窗与 5000 tick 竞争窗口的开销未评估。
- 影响：B2 消融表；50 万规模性能。
- 解法：先做「只修剪不生长」与「只生长不修剪」两条单变量实验；给每簇设硬预算与事件日志。
- 验证：结构指标（K_avg、回收效率、竞争胜出率）在固定 seed 下方差可控。

**T5 元可塑与边界刹车的交互**
- 问题：`1/p` 压缩学习率，`γ_brake` 压制边界，两者叠加可能使未巩固突触几乎不学。
- 解法：分别消融，测「权重分布熵 + 到达率」双指标。
- 验证：无饱和（satHI < 5%）、无冻结（有效学习率 > 20% 初值）。

**T6 记忆的可寻址性与容量**
- 问题：模式补全要求时间排序相关性 ≥0.7，但未给容量估算（多少签名 / 多少神经元 / 多长序列）。
- 解法：先做 100/500/1000 签名的容量-保真度曲线；用循环连接强度与抑制门控做扫描。
- 验证：ρ≥0.7 的最大签名数，及睡眠重放后的保持率增益。

**T7 基元链生成的合法性**
- 问题：链式 STDP + 侧抑制能否稳定生成「不循环、不重复、能终止」的序列，缺机制保证。
- 解法：加终止基元 + 最大长度 + 重复抑制；先固定 10 个基元、长度 ≤5 的小任务。
- 验证：合法序列率、平均长度、循环率。

**T8 解码校准**
- 问题：低脉冲计数下泊松独立假设过度自信。
- 解法：温度缩放 / 贝叶斯平滑 / 校准集；报告 ECE 而不只报熵。
- 验证：ECE < 0.1；可靠性与准确率曲线。

**T9 事件驱动 + 惰性结算的复杂度**
- 问题：设计只给原则，没给队列结构与时间戳索引方案；如何保证 O(活跃) 而非 O(N)。
- 解法：分层时间轮 + 按簇的待结算链表；每次访问结算 Δt。
- 验证：每 tick 遍历数与发放率成正比；空转 tick 开销 < 1%。

**T10 回滚一致性**
- 问题：权重回滚、资格迹不回滚 → 幽灵更新。
- 解法：回滚后迹按 `exp(-Δt/τe)` 重算或清零；写入检查点元数据。
- 验证：回滚后 100 tick 内权重漂移 < 阈值。

## 5. 开发计划

### 5.1 总原则

1. **先证伪，后建设**：M1 不过，不写容器、不写 SNC、不碰 B2 以上。
2. **单变量隔离**：一次只改一项，记录 median + 种子分布 + 消融。
3. **独立脑实例**：每个 benchmark 独立检查点目录，不继承结构。
4. **判据先定，代码后写**：判据进 `spec/judgments.md`，代码引用判据版本。
5. **能复用不自研**：管道用现成件，语义层自研。

- 伴生灵：选择性学习、情绪簇、碎片重放（不活跃 30 min + 槽 >50%）。
