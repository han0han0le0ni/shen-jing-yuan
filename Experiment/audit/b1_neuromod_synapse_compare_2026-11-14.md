# 单突触资格迹对照：B1 规则 vs neuromod 0.6.0（§1 第 4 项 / v1.19）

> 生成时间：2026-11-14 20:00 · τe 对齐 **100** · 驱动序列 3000 个脉冲对（gap∈{1,2,5,10,30,100}，dt∈[-20,20] 整数步，确定性 LCG 生成，两侧同一文件）
> C 侧：`tools/nm_compare.c` 按**核心同常数**手写（τ_stdp=50、a₊=0.1、a₋=0.12），核心 `benchmark1_core.c` 零改动；Rust 侧：`ref_neuromod` 调 crate 的 `EligibilityTrace`。
> Rust 工具链：rustc 1.100.0 / cargo 1.100.0；crate `neuromod 0.6.0`。

## 0. 结论

1. **衰减律**：C 侧 `exp(-1/τ)` = 0.990049833749，Rust 侧 = 0.990049839020（相对误差 5.32e-09）→ **等价**。
2. **STDP 核**：归一化后在 7 个采样点上的最大偏差 **0.2971**，τ₊ 不同（B1 50 vs 20）；幅度比 Rust/C = 0.0848（A₊ 0.01 vs 0.1，约 10×）→ **不等价**。
3. **迹曲线**（3000 点，按各自峰值归一化）：Spearman ρ = **0.984**，Pearson r = 0.986 → 同形。

**判定**：两条规则的**迹衰减律是同一个公式**，但**核不等价**——`neuromod` 的 A₊/A₋/τ± 是**编译期常量**（0.01/0.012/20），`RmStdpConfig` 只暴露 τe / reward_lr / w_min / w_max，**无法对齐到 B1 的 0.1/0.12/50**；因此「统计等价」在核层面**结构性不成立**，不是调参能解决的。

这意味着 §1 第 4 项要么（a）由负责人重新定义等价口径（只比衰减律/归一化迹曲线，不比核），要么（b）如实记为「两侧规则不等价」并保留为 B1 的未通过理由。**本轮不代为选择。**

## 3. 诚实边界

- 这**不是**整网等价：拓扑、RNG、权重归一化（L1）都不同，本节只比单突触层面的迹与核。
- C 侧是**按核心同常数手写**的对照实现（核心零改动），不是直接调用核心；因此结论覆盖「规则」，不覆盖「核心代码路径」。
- Rust 侧用 f32、C 侧用 double，衰减因子存在 ~1e-7 量级差异，已在容差 1e-5 内。
- 驱动序列是合成的（非 B1 真实脉冲对）；B1 核心不暴露单突触 Δt 序列，要拿真实序列必须改核心，违反冻结。
