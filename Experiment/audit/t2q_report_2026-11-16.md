# T2q 报告 · 0.54 的责任归属：闭环分布上的开环单步上界（2026-11-16）

> 预注册：`audit/t2q_prereg_2026-11-16.md`（运行前落盘）
> 承接 §6.34（K=1,g=1 8 seed 合并 0.5398、7/8 seed ≤0.80、≤0.40 仅 2/8）
> **不是 B2 验收**；B2 保持停止；**阈值零变更**。

## 0. 结论先行

在**K=1,g=1 训练后真正的闭环访问分布**上（seed 101，38400 个采样点，stride 10）：

| 读出源 | 测试单步 MAE | 常数基线 | MAE/基线 | R² | 判定 |
|---|---|---|---|---|---|
| **input（1056 维）** | 0.1284 | 0.2459 | **0.522** | **0.672** | **部分**（有信息，但线性只能用掉 2/3 方差） |
| **hidden（3500 维）** | 0.2906 | 0.2459 | **1.182** | **−0.679** | **表征不足**（比常数基线更差） |

**0.54 的责任在隐藏层，不在解码。** 隐藏层在这个分布上**线性完全读不出 ω***（R² 为负），
而 input 侧仍有 R²=0.67 —— 也就是说 K=1 的 WTA 之所以有效，是它**绕过了 PDc 的平均抵消、让 input 驱动的运动神经元直接说话**，
而不是「hidden 变有用了」。这与 §6.27/§6.29/§6.30 在四个不同读出族上得到的结论完全一致，只是这次换到了真正的闭环分布。

- 密度：input 0.1487，hidden 0.2021（同一次运行、同一分布）

## 2. 判定（按预注册）

预注册只对 input 给了三档（≤0.25 / 0.25–0.75 / ≥0.75）：

| 分支 | 是否命中 |
|---|---|
| ≤0.25 → 表征够用，瓶颈在解码/学习 | ✗（0.522） |
| **0.25–0.75 → 部分** | **✓（0.522）** |
| ≥0.75 → 表征不足 | ✗ |

hidden 是预注册之外的补充对照（同一次运行的另一层），按同一口径读：
**1.182 / R²=−0.679 → 与 §6.27 的 1.51 同方向（劣于常数基线）**，说明「hidden 无边际信息」这个结论**在闭环分布上同样成立**。

## 3. 机制整合（把 §6.28–§6.34 串起来）

1. **为什么 K=1+误差项能到 0.54**：WTA 只让 1 个（或 3 个）winner 说话，PDc 的对称平均不再把方向洗掉；
   误差项把 winner 的偏好方向逐步校准；而 winner 主要由 **input 层经随机稀疏投影**驱动 → 等价于「直接读 input」。
2. **为什么停在 0.54 而不是 0.40**：input 侧线性只能解释 67% 的 ω* 方差（单步），
   而 hidden 侧 R² 为负 → 网络没有可用的内部表征，命令精度受限于「input 特征的线性可读性」。
   参照：drive-direct 分布上 input 线性 MAE/基线 0.47（§6.22）、retarget 均衡后 0.068（§6.24）——
   **闭环分布比均衡开环分布更难**，这一条现在有了同口径的量化。
3. **与 §6.28 判「直通/残差不可行」并不矛盾**：那次改的是拓扑（fan 24）且仍用 PDc 解码，
   失败机制是「运动层被压窄 + 对称平均抵消 → 命令≈0 自锁」；这次不改拓扑、只改解码，反而通了。
   → 「input→motor 直读」这条路本身可行，卡它的是**解码**与**随机稀疏初始化**，不是直读概念。

## 4. 诚实边界

- 这是**开环单步上界**（给定访问到的 state 预测 ω*），**不是闭环上界**：读出没有反馈进环路，不能直接等于「换成线性读出后能到多少」。
- **单 seed（101）**；§6.34 已证逐 seed 离散 0.18–0.99，本项只作机制定位，不做统计推断。
- 训练/测试取自**同一次运行**的不同 episode 段（280–299 / 300–319）；早期未收敛段的分布未使用。
- `ω*` 是解析 `Jᵀ` 侧信息，落地仍需内部模型；**训练的权重没有落盘接口**，因此无法把 β 写回做闭环验证（这是工具缺口，如实记录）。
- 不改阈值、不改判据、不动学习规则本体。
