## 0. 需要签字的理由

要动两处**动力学**，都不是现有 CLI 能覆盖的：

1. **新增核心参数**（`hidden_base_current` / `motor_base_current`）——属核心改动，默认值必须保持逐位不变；
2. `--psp` 扫参——CLI 已有，但它同时缩放全部突触电流，属"改驱动幅度"。

两者都不触碰学习规则本体（STDP 核 / 资格迹 / 奖励 / 调度），也不改判据与阈值。

## 3. 判定规则（阈值零变更，机制口径）

主判据（四条件同时满足才算"离开饱和"）：

| 指标 | 目标 | 依据 |
|---|---|---|
| 隐藏密度 | **0.05–0.15**（占上限 20–60%） | 文献最优活动为低活动区且性能对活动非单调；我们当前 0.243 |
| ISI-CV 中位数 | **≥ 0.30** | 0 = 完全定频；当前 0.000 |
| 参与比 PR | **≥ 50**（当前 2.36） | 状态有效维度必须显著高于"一个时钟相位" |
| \|lag-4 自相关\| | **≤ 0.50**（当前 0.996） | 4-tick 锁定必须解除 |

| 结果 | 判定 |
|---|---|
| 任一臂四项全中 | **工作点修复成立** → 进 M2（同臂重跑 K=1+g=1 闭环，判 `median ≤ 0.40`） |
| 只有 A 组（切基电流）命中、B 组不命中 | **基电流是主因**，输入增益是次因 → M2 只带 `--hidden-base` |
| 只有 B 组命中 | **输入增益是主因** → 基电流参数保留但默认不改，M2 只带 `--psp` |
| 六臂全不命中 | **工作点不是这两个旋钮能修的**（例如需要 E/I 抑制通路或权重归一化）→ 本线关闭，转 M3（ALVA/ALIF）或换任务，需负责人再定 |

**明确不许做的事**：不得因为某一臂"分数看起来更好"就改判定口径；M1 不看闭环分数（那是 M2 的判据）。

## 4. 必报诊断与边界

- 必报：上表 7 项 × 6 臂 × 3 seed（含均值与逐 seed）；
- 必报：A0 与 M0 的差异（若 A0 不能复现 0.2430/0.000/2.36，先查 DLL/构建再谈其余）；
- 未测：抑制性突触（本网络全兴奋）、突触归一化/内稳态、ALIF 慢变量、运动层基电流；
- 不外推：单任务（2 连杆到达）、单拓扑（1056/3500/2×250）、`avg_conn=8`。
