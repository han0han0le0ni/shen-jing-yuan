## 0. 为什么是结构、而不是继续调参

三条已落地的事实把路堵到只剩这一条：

1. `§6.43`：e-prop 修复后 `medD = 0.2181（9/10 ≤ 0.40）`，但 `medR = 0.2384` 只有 **5/10 ≤ 0.20**
   —— **跨过门槛、没过判据**，差的是分布右尾（0.22–0.43 五个 seed）。
2. `audit/m4_eprop_report_2026-11-17.md` §3.1/§3.5：`lr = 1e-5` 与 `3e-5` 同区间、640 ep 不涨
   ⇒ **不是学习率、不是训练时长**。
3. `audit/m4_eprop_report_2026-11-17.md` §9b（尾部归因 D-a…D-e）：**五个维度都无法区分快慢 seed**
   —— 运动层 `corr(drive, pref) ≈ 0`（快 **0.010** / 慢 **0.047**；2026-11-18 修正层边界后重算，
   旧值 0.048/0.060 作废，见主报告 §9b 勘误）、`sd(ω)` 0.297/0.286、胜者熵 0.966/0.962、
   低频相干 0.194/0.188；且未训练权重的机会水平是 `medD = 1.058`（0/8）。
   ⇒ **调参杠杆已用尽**，尾部差异更像 seed 个体差异；要动只能动**表征本身**。

## 1. 假设与可反驳预测

**H2**：B2 判据过不去的剩余原因，是**固定随机拓扑的入度结构不足**——
运动层与隐藏层之间的连接没有覆盖到"对任务有用"的隐藏子群，导致部分 seed 的读出天生不可分。

**可反驳预测（先写死）**：
- 若 H2 成立，则活动依赖生长应把 `medR` 的 **p90（尾部）** 从 0.43 压到 ≤0.20 附近，
  使 **10 seed 中 ≥8** 过线；而**同数量随机生长**（臂 C）**不能**达到同样效果；
- 若臂 B 与臂 C 差异 ≤0.05，则 H2 被反驳：收益只来自"多连接"的冗余，不是结构选择。

## 2. 实现规格

| 项 | 规格 |
|---|---|
| 开关 | 新增 `hp.struct_mode`（默认 **0** = 现行为逐位不变）；`net2_set_param("struct_mode", …)`；host `--struct` |
| 允许动作 | **只做 I→H、H→M、H→H 的生长**；**不做剪枝**（首版避免"删掉已学到的连接"这一混杂） |
| 触发时机 | 每 `S_INTERVAL = 100 ep` 执行一次"结构轮"（在 episode 边界，不打断学习） |
| 生长依据 | 用最近 `W = 20 ep` 的**共激活计数** `coact[pre][post]`（uint16，仅累计同期发放的 (pre,post) 对） |
| 选择规则 | 对每个**入度不足**的运动神经元（`fan-in < F_MIN = 150`），从**未连接**的候选里按 `coact / (1 + fan-in_pre)` 取 top-k 补到 `F_MIN`；隐藏层不强制入度 |
| 新突触权重 | `w_new = 0.5 × median(w of same path)`（同通路中位数的一半，避免新边一上来就过强） |
| 预算上限 | 总突触数 `≤ 1.20 × S0`（`S0 = 115140` ⇒ ≤ 138168）；超出即停止生长并记录 |
| 每轮上限 | 单轮新增 ≤ `0.02 × S0`（约 2.3k），防止一次性改坏动力学 |
| 学习规则 | **完全不动**：e-prop 全通路、`α=0.3`、`lr=1e-5`、ADAM 逐 tick、`error_gain` 关闭 |
| 逐位兼容 | `struct_mode=0` 时，`--preset m2 --decode-mode wta --wta-k 1 --reward-mode potential --seed 202 --episodes 320 --eprop --eprop-lr 1e-5` 的 CSV **SHA256 必须与 `data_b2/m4/fix320/ep_lr1e05_s202.csv` 一致**；不通过即回退 |
| 内存 | `coact` = 4500×556 uint16 ≈ 5.0 MB（可用 `uint16` 饱和计数）；新增状态 ≤ 6 MB |
| 速度 | 结构轮本身是 O(S0)；**不允许**影响主循环，单步耗时应与 `struct_mode=0` 相同 |

**明确不改**：`psp_factor`、`hidden_base_current`、`motor_base_current`、初始化、解码（WTA k=1）、
奖励塑形、`error_gain` 语义、e-prop 的伪导数与 ADAM 语义、B2 判据阈值。

## 3. 臂设计（10 seed = 101/202/303/404/505/606/707/808/909/1010）

| 臂 | 内容 | 目的 | 运行数 |
|---|---|---|---|
| **A. 固定拓扑** | e-prop 全通路（**复用** `data_b2/m4/ep_8s/` + `seed_extra/`） | 对照，不重跑 | 0 |
| **B. 活动依赖生长** | `struct_mode=1`，按 §2 规则 | H2 主检验 | 10 |
| **C. 随机生长（对照）** | `struct_mode=2`：新增突触**数量与臂 B 同**，但 (pre,post) 对随机（固定 seed 决定） | 排除"多连接=更好" | 10 |
| **D. 强制入度（无共激活）** | `struct_mode=3`：补到 `F_MIN` 但候选**按索引顺序**取（不看共激活） | 分离"选择规则"与"补足入度" | 10 |

共同参数：`--preset m2 --decode-mode wta --wta-k 1 --reward-mode potential --episodes 320 --eval-episodes 20
--eprop --eprop-alpha 0.3 --eprop-lr 1e-5`。总运行数 = **30 次**（约 6 min/次，24 核并行 ≈ 15 min/批）。

|---|---|

| held-out medD（固定四目标） | ≤ 0.25（M4 为 0.2058，容差 +0.045） |

### 4.3 结论映射（先写死）

| 观测 | 结论 |
|---|---|
| B 过判据（≥8/10）且 C 与 B 差 >0.05（C 更差） | **H2 成立**：结构选择有效 ⇒ 提请把 B2 判为**通过**（需另签字） |
| B 过判据，但 C 也过判据且差 ≤0.05 | 收益来自**连接冗余**而非选择 ⇒ B2 记为"通过（机制=冗余）"，并单列 H2 被反驳 |
| B 未过判据（<8/10） | **结构不是瓶颈** ⇒ B2 判据维持**不通过**，按 §2 门槛的用途终止此项，转 B3 或任务决策 |
| D ≈ B | 说明关键只是"补足入度"，共激活选择无额外贡献（记录，不改变判定） |
| 任何 seed `satHi > 1%` 或突触数超限 | 记录为"实现不可用"，**不得**用调参后结果替代 |

## 5. 已知风险（提前写明）

1. **预算本身就可能是混杂**：臂 C 若也改善，说明"多连接"即可。故 C 不是可选项，是必需项。
2. **生长可能破坏已学的动力学**：新突触即使权重很小也会改膜电位；若 `medD` 反而劣化，
   按 §4.3 如实记录，**不回调** `w_new` 系数重跑（那是事后调参）。
3. **只生长不剪枝 = 单调变密**：65 万突触后单步耗时会上升；本项把上限设 1.2× 就是为了限住这一点。
4. **单任务单拓扑**：结论不外推到 B1/B3；`medR ≤ 0.20` 仍是唯一判据线。
5. **实现风险**：若 2 天内做不出 §2 的逐位兼容，**停止本项**并如实报告"实现未通过准入"。
