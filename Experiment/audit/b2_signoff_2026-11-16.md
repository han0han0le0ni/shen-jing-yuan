## 1. 授权依据（为什么需要这次改动）

| 证据 | 结论 |
|---|---|
| §6.27（T2g） | hidden 与 input 联合读出**不如只读 input**；同维随机子集更差 1.23 → 不是维度问题 |
| §6.29（T2i） | 非线性解码头（RFF 512 / MLP 32）在 hidden 上只到 0.88–0.90，「换解码头」不成立 |
| §6.30（T2j） | 速率码读出 hidden 最好 0.9498，仍不可用 |
| §6.35（T2q） | **在控制器真正访问的闭环分布上**，hidden 线性读 ω* 的 **R² = −0.679**（劣于常数基线），input 为 0.672 |

→ 隐藏层在**四个读出族 + 闭环分布**下都读不出可用信息，而它从未被任何学习信号塑形（误差通道只作用于
「突触后是运动神经元」的突触，即 I→M 与 H→M；**隐藏层自己的输入突触完全不受误差影响**）。

## 2. 授权范围（**只**允许以下改动）

- 核心新增参数：
  - `error_scope`：`0` = 仅运动层输入突触（**默认，旧路径逐位不变**）；`1` = **额外**作用于隐藏层输入突触。
  - `error_scope_gain`：隐藏层信用项缩放，默认 `0.1`。
- 隐藏层信用方向（反馈对齐式）：`hid_dir[h] = Σ_m w_{h→m} · tanh(pref_m / 0.15) · e_m`，
  其中 `m` 遍历该隐藏神经元投影到的运动神经元，`e_m` 是该运动神经元所属关节的逐 tick 误差。
  隐藏层突触更新：`dw += lr · error_gain · error_scope_gain · hid_dir[post] · credit`，
  仍要求**突触前本 tick 发放**。
- host 新增 CLI：`--error-scope motor|hidden`、`--error-scope-gain F`；写入 `meta.json`。

## 3. 不在授权范围内（明确禁止）

- **不改** §2 判据、B2 阈值（median ≤0.40）、B1/B2/B3 启动条件。

- 不写容器、不写 SNC、不回 B2 调 lr/shaping。
