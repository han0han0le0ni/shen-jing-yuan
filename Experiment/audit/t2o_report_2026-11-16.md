# T2o 报告 · 选优强度 K 的剂量响应（K∈{1,3,8} × g∈{0,1}）（2026-11-16）

> 预注册：`audit/t2o_prereg_2026-11-16.md`（运行前落盘）；K=3 两格复用 T2n（`data_b2/t2n/`）。
> 承接 §6.32（WTA(K=3)+`g=1` → 0.5595，−53%，到达 14/60）
> **不是 B2 验收**；B2 保持停止；**阈值零变更**（判定线仍 `median ≤ 0.40`）。

## 0. 结论先行

1. **窄选优档（K=1 与 K=3）等效**：0.5843 vs 0.5595（差 4.4%），到达 17/60 vs 14/60 —— K 在窄档内不是变量。
2. **宽选优（K=8）退回抵消**：0.9546（只 −19.3%），到达 1/60 —— 与 `g=0` 的 1.1826 几乎没差别。
   → 选优宽度有**阈值效应**：足够窄才抑制 PDc 式平均，K 大了平均又回来了。
3. **「饱和是唯一残留瓶颈」不成立**：K=1 在 `g=1` 下 satHI 只有 12–14%（`g=0` 是 6–10%），几乎没被推高，
   但性能停在 **0.58**，仍不达 0.40。→ 下一层瓶颈不在权重饱和。
4. 判据：**部分成立**（`≤0.80` 且 `Δ ≤ −20%` 命中 K=1/K=3），`≤0.40` 与「≥2/3 seed 各自 ≤0.40」都未达成。

## 1. 协议

- 六格：K ∈ {1, 3, 8} × `error_gain` ∈ {0, 1}；seed 101/202/303；320 ep + 末 20 轮冻结评测（每格 60 评测轮）
- K=1/K=8 新跑（`--decode-mode wta --wta-k {1|8} --error-gain {0|1}`，零代码改动）；K=3 复用 T2n
- 汇总口径统一由 `tools/t2_arm_summary.py` 计算（只取 `is_eval==1`）

## 3. 判定（按预注册分支）

| 预注册分支 | 是否命中 |
|---|---|
| 某 K：`M(K,1) ≤ 0.40` 且到达 ≥3/60 且 ≥2/3 seed ≤0.40 → **成立** | ✗（K=1 只有 1/3 seed ≤0.40；K=3 同） |
| 某 K：`≤ 0.80` 且相对 `M(K,0)` 改善 ≥20% → **部分成立** | **✓ K=1（−45.7%）、K=3（−53.3%）**；K=8 ✗ |
| 三个 K 两两差 <10% → K 不是变量 | 部分：K=1 vs K=3 = 4.4%（等效）；但 K=8 比 K=3 差 **70%** |
| 某 K：`M(K,1) > M(K,0)` → 该 K 下误差项仍有害 | ✗（K=8 只是没用，仍是 −19.3%） |

→ **判定「部分成立」**：窄选优（K≤3）+ 误差通道有效，宽选优（K=8）失效，`≤0.40` 未达。

## 4. 机制

1. **阈值效应**：K 越大，winner 集合越多样，`pref_omega` 平均越接近 PDc 的平均 → 抵消回归。
   K=8 的到达数掉回 1/60 与 `g=0` 无异，正是「又变成平均解码」的表现。
2. **饱和不是残留瓶颈**：K=1 的 satHI 只从 6–10% 涨到 12–14%，权重分布基本健康，但闭环仍 0.58
   → §6.32 里「D 臂 22–30% 饱和」只是 K=3 的副产物，不是性能上界的成因。
3. **剩下的上界候选**：① 隐藏层从未被任何学习信号塑形（读出只能用输入侧/未训练的 hidden）；
   ② 命令由极少数 winner 决定 → 抖动大（K=1 的 seed 间 0.375–0.841）；③ 1200 tick 预算下的控制律本身。
   上一条与 §6.26/§6.29 的开环上界（input 线性 0.47、非线性 0.40）量级吻合 —— **0.56 已经贴到开环上界附近**。

## 5. 诚实边界

- 3 seed，逐 seed 离散 0.18–0.99（K=3）/0.375–0.841（K=1），**合并不等于稳定**；不能用单 seed 下结论。
- K 只取 1/3/8 三个点（端点声明，非网格），中间值未扫；不外推。
- `ω*` 仍为解析 `Jᵀ`（上界侧信息）；隐藏层未被塑形；**命令–误差相关性未测**（无逐 tick 导出）。
- K=3 两格来自 T2n（同 seed/同参数），不是本次重跑；跨实验复用的前提是参数逐项一致，已在预注册中声明。

## 6. 下一步

1. **加 seed 到 6–8 个**（K=1 与 K=3 各补 3–5 个）：当前方差主导，任何「成立」结论都要先降方差。
2. **找到 0.58 的成因**：用 §6.26 的 dump/DAgger 机制，在**K=1 闭环访问到的分布**上重训静态读出，取开环上界；
   若上界也 ~0.5 → 确认是表征限制（隐藏层未被塑形）；若上界 ≤0.2 → 是读出/学习规则问题。
3. **T2m（稳态）降级**：饱和已证明不是主因，除非上一步显示权重分布有别的病理。
4. 不做：Python 仿真（12 min/格已够）、回 B2 调参、再扫 `error_gain`。
