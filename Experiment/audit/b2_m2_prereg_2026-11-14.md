# B2 · M2 可行性探针 预注册（2026-11-14）

> 运行前落盘。依据 `spec/judgments.md` §0（全局口径）、§2（B2 判据与 M2 门槛）、§5（统计规范）；
> 设计大纲 §M2（「规模：5000 神经元；只加异构输出层 + PDc 群体解码 + 势能塑形奖励」）。
> **B1 已通过（判据 v1.20 §6.21），本节才允许启动 B2。** B1 核心 `benchmark1_core.c` 不参与、不修改。

## 0. 要回答的问题

M2 门槛（§2）：**5000 神经元、仅异构输出 + 群体解码 + 势能塑形，10 seed 中 ≥6 个 median(dist_ratio) ≤ 0.40
且 g=0 到达率 > 0**，才允许上结构可塑（竞争性发生）。

历史状态：`data_b2/` 120 次运行 0 达标，最佳 median 0.4164；且历史配置依赖
`cf_lambda=1`（解析逆运动学期望速度）与 `error_gain>0`（攀爬纤维教师），**不是 g=0**。
本探针把这两条通道关掉，只留「环境奖励 + 势能塑形」。

## 1. 固定协议（不得事后改）

**网络**：总数 **5000** = input 1000（其中 56 个本体感觉）+ hidden 3500 + motor1 250 + motor2 250，
`avg_conn = 8.0`，`net2_init(seed)` 单一随机源。

**三个新增件（M2 的全部内容）**：
1. **异构输出层**：仅运动层，`hetero_tau=0.25`（膜衰减对数正态 σ）、`hetero_thresh=2.0`（阈值高斯 σ，mV）、
   `hetero_tune=0.25`（调谐宽度对数正态 σ）；隐藏层与输入层保持同构。
2. **PDc 群体解码**（新 `decode_mode=3`）：`ω = Σ_i s_i·pref_i / max(1, Σ_i s_i)`，`s_i∈{0,1}` 为本 tick 发放，
   `pref_i∈[-0.5,0.5]`；无发放时 ω=0。**不改** k-WTA 既有两条路径（mode 0/2）。
3. **势能塑形奖励**：`r = 1 − d_t/d_0`（`d_0` 为 episode 初始末端距离），`use_reward_baseline=1`。

**g=0 强制（硬约束）**：`cf_lambda=0`（关解析 IK 期望速度）、`error_gain=0`（关攀爬纤维教师）、
`novelty_gain=0`；**输入只用状态**：`prop_mode=raw`（仅 θ1/θ2 本体感觉，24 维本体感觉 + 位置群体编码），
不使用 `tag2/tag3`（目标方位差，由解析几何生成）。`prop_mode=full`（含 56 维）只作为对照臂，**不计入通过判定**。

**预算（§0.3）**：每 episode **固定 1200 tick**（`--budget 1200`），到达后**不提前终止**，继续跑满预算；
到达率与首次到达 tick 单独记录。

**目标**：随机多目标（`target_mode=0`，与目标生成器同分布），每 episode 重置关节到 `(0,0)`、末端在 `(2,0)`。

**训练/评估**：每 seed 训练 **300 episode**；随后**评估 20 episode**（同样 1200 tick 预算），
评估期 `use_reward_modulation=0`（冻结学习，权重与迹不再更新，仅前向）。
学习率阶梯沿用现有 host 规则（<500 ep: 0.35；<2000: 0.20；else 0.04），不另调。

**seed**：`MASTER_SEEDS = [101,202,303,404,505,606,707,808,909,1010]`（10 个）。

## 2. 判定规则（预注册）

对每个 seed：
- 取评估 20 episode 的 `dist_ratio = final_dist / init_dist`；
- 按 §0.4 剔除 `init_dist < 0.10` 的 episode（`invalid`），并单独报告剔除数；
- `median` 用标准定义（偶数取中间两项均值）；
- `arrival_rate` = 评估期在 1200 tick 内首次到达（`d ≤ 0.15`）的 episode 占比。

**通过条件（与 §2 门槛一致，逐字）**：`median ≤ 0.40` 的 seed 数 **≥ 6/10**，且**总到达率 > 0**。

**失败动作**：不通过 → 停止 B2，回 T1/T2 研究（前向模型 / 解码可学性），**不得上结构可塑**。

## 3. 排伪对照（同 seed，各 3 seed，仅用于归因，不参与判定）

- `no_shape`：`reward_mode=combo1`（去掉势能塑形，其余不变）→ 检验塑形是否真的在起作用；
- `no_hetero`：`hetero_*=0`（其余不变）→ 检验异构输出是否必要；
- `decode_wta`：`decode_mode=0, wta_k=3`（其余不变）→ 检验 PDc 是否必要。

每条对照只改一个量。

## 4. 已知风险（写在跑之前）

- **历史最优 0.4164 与本门槛 0.40 只差 0.016**：本探针同时关掉了两条教师通道，可能直接掉到 0.7+；
  若如此，结论是「g=0 下 M2 门槛不可达」，按失败动作停，而不是回头打开教师通道。
- 5000 神经元 + 1200 tick × 320 ep 的单 seed 运行量约 4×10⁵ tick；若单 seed 超过 5 分钟，
  先减少评估 episode（20→10）并在报告中注明，**不改训练 episode 数与预算**。
- PDc 在发放稀疏时会给出 0（无输出），表现为「不动」；若评估期出现 >50% episode 完全不动，
  这是发现而非 bug，如实报告（不回头调 sparsity）。
