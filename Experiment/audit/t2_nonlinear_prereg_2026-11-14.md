# T2i · 非线性读出 预注册（2026-11-14）

> 运行前落盘。承接 §6.27（hidden 线性无边际信息）、§6.28（直通/残差失败，B2 保持停止）。
> **不是 B2 验收**；B2 既判 FAIL 与停止状态不变；**阈值零变更**（0.40 闭环线不参与本实验判定，见 §3）。

## 0. 问题

T2g 的结论是「**hidden 的线性**可读性差（MAE/基线 1.51，DAgger 也救不了）」。
但线性不可读 ≠ 不可读：hidden 是 3500 维二值发放，ω* 可能是它的**非线性**函数。

- 若 hidden 的**非线性**读出能把 MAE/基线压到线性 input 的水平（≤0.50）→ hidden **有信息**，
  只是线性解码不够 → 修法是**可学习的非线性解码头**，而不是改拓扑/换编码（§6.24 的「换编码」保持关闭）；
- 若 hidden 的非线性读出仍 ≥0.90 → hidden 里**几乎没有可用信息** → 唯一剩下的路是**时序/速率编码**（T2 下一步）。

## 1. 协议

**数据（全部既有，不再跑新的 C 采集）**
| 集 | 来源 | 样本 | 层 |
|---|---|---:|---|
| A | `data_b2/t2bal/dump_{input,hidden}.bin`（`--drive-direct --retarget 60`，seed 11） | 2400 | input 1056 / hidden 3500 |
| B | A + `data_b2/t2dag/dump_{layer}_r1.bin`（DAgger 第 1 轮 on-policy 状态） | 4800 | 同上 |

- 划分与 §6.27 完全一致：episode 0–13 训练、14–19 留出（聚合集按 episode 列切分，两轮同 seed 同目标序列）；
- 目标：解析 ω*（两维），与既有上界同一标签；
- 指标：留出集单步 `MAE`、常数基线 `MAE_base`、**比值 `MAE/MAE_base`**（与 §6.23–§6.27 同口径，可横向比）。

**三种读出族（同一划分、同一指标）**
1. **线性 ridge**（基线，α 由训练集 3 折 CV）——即 §6.27 的数；
2. **随机特征 ridge（RFF-ReLU）**：`h = relu(X·W + b)`，`W ~ N(0, γ²/d)`，宽度 `m=512`，
   `γ ∈ {1, 3}`，`α ∈ {0.1, 1, 10, 100}`（按训练集 3 折 CV 选 γ、α）；
3. **小型 MLP（numpy 手写反向传播）**：`d → 32 → 2`，ReLU，Adam（lr=1e-3，batch 256），
   输入标准化，早停于**训练集内单一 80/20（按 episode 分组）验证切分**（patience 10，最多 60 epoch）。

> 修订记录（2026-11-14 23:5x，**运行前**）：原写「3 折 + 64 单元 + 200 epoch」，因本机只有 numpy、
> 无向量化框架，实测该配置单次拟合 >5 分钟，改为 32 单元 / 60 epoch / 单一内部切分；
> 只影响读出族容量（更保守，不利于 PASS），不改变 §3 判定线。

> 本机无 torch/sklearn（只有 numpy 2.4），故用 numpy 实现；RFF 与 MLP 都只训练**读出层**，不动 SNN。

## 2. 关键限制（写在跑之前）

**非线性读出无法注入闭环**：核心的外部读出是「线性 × 发放」的，MLP/RFF 的权重无法写回
（`--load-readout` 只接受 2×d 的线性系数）。因此本实验**只有开环指标**，
不能给出闭环 median。这不是遗漏，是接口限制——闭环要等 Python 侧重实现输入编码 + 臂物理才能做（列为后续）。

## 3. 判定规则（主判定用**相对**指标，不用 0.40 闭环线）

以同一集上的**线性 input** 为参照（集 A：0.47；集 B：0.49）：

| hidden 非线性 `MAE/MAE_base` | 判定 |
|---|---|
| **≤0.50** | **hidden 有信息、只是线性不可读** → 修法改为「可学习非线性解码头」（需签字） |
| 0.50–0.80 | **有限可读**（弱）：记为部分信息，不足以支撑改架构 |
| **≥0.90** | **hidden 几乎无可用信息**（与线性 1.51 同量级）→ 转**时序/速率编码** |

补充读法：若 input 的 RFF/MLP 显著优于其线性（0.47 → <0.30），说明**输入侧**还有非线性余量，
可作为「解码头」的正面证据；若 input 也收益很小，则说明整条链的信息都已接近线性可提取上限。

## 4. 诚实边界

- 只有开环；开环好不代表闭环可用（§6.25 已证明两者会分离）。
- 单 seed、单划分；非线性族的搜索空间远大于线性，本实验只取**一个固定结构**（RFF m=512 / MLP 64 单元），
  **不能**排除「更大/更深的网络可读」——结论只针对这两个代表。
- 早停用训练集内 3 折，测试集（14–19）始终不参与任何选择。
- 不改学习规则、不改 B2 判据、不写容器、不写 SNC。
