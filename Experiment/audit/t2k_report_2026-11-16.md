# T2k 报告 · 攀爬纤维误差通道（error_gain）单变量（2026-11-16）

> 预注册：`audit/t2k_prereg_2026-11-16.md`（运行前落盘）
> 借鉴依据：`audit/snn_reference_review_2026-11-16.md`（Nengo/PES、小脑自适应滤波器、PopSAN、FORCE）
> **不是 B2 验收**；B2 保持停止；**阈值零变更**（判定线仍 `median ≤ 0.40`）。

## 0. 结论先行

**「把误差信号灌进突触」不成立，而且方向是负的**：`error_gain` 从 0 抬到 1 / 5，
评测段 median 距离 1.0966 → **1.2766 / 2.0108**（更差），到达数 1/60 → 0/60 / 3/60。
根因可诊断：误差项让 `I→M` 权重**单调饱和**（`satHI` 15.3k → 18.5k/20.4k，占 24.8k 的 73–82%），
运动层被推到常数上限 → 手臂飞走。这是**缺稳态/归一化**，不是「误差信号没用」。

## 1. 协议（与预注册一致）

- `--preset m2`（1000/3500/2×250，`avg_conn=8`，PDc 解码，budget 1200，`cf_lambda=0`，`novelty_gain=0`）
- 单变量：`--error-gain ∈ {0, 1, 5}`；seed `101/202/303`；`--episodes 320 --eval-episodes 20`
- 评测段 = 最后 20 轮（`use_reward_modulation=0`，权重冻结）；每臂 3×20 = **60 评测轮**
- `g=0` 为对照，须复现 §6.22（median 0.8903–1.2278）

## 3. 判定（按预注册规则逐条对）

| 预注册分支 | 是否命中 |
|---|---|
| 任一 `g`：median ≤ 0.40 且到达 ≥ 3/30 → 成立 | ✗ |
| median 0.40–0.80 → 部分成立 | ✗ |
| 相对 `g=0` 变化 <10% → 不成立 | 部分：`g=1` 是 +16%、`g=5` 是 +83%，**方向为负** |

→ **判定「不成立」**，且比「无变化」更强：误差通道**主动有害**。

## 4. 机制解读（与 §6.28 同源）

1. **单调饱和**：手臂不动时 `ω ≈ 0`，`e ≈ ω*`（恒指向目标），`dir = tanh(pref_omega/0.15)` 对每个神经元是**固定符号**，
   于是 `dw` 每 tick 同号累加 → `I→M` 权重一路顶到 `WEIGHT_MAX=10`（`satHI` 73–82%），
   过程中没有任何项把它拉回。公开项目里抑制这种漂移的是**梯度 + 权重归一化/Dale 约束**，我们没有。
2. **PDc 平均会抵消方向**：与小脑模型不同，我们的解码是 `Σs·pref/Σs`（§6.28 已把这条列为自锁机制假设）。
   单突触按偏好方向被推，但对称偏好互相抵消，净命令不跟随误差，只剩「整体饱和 → 常数输出」。
3. 因此本实验**没有证伪**「误差驱动有用」，而是证伪了「在我们这套解码 + 无稳态项的规则下，直接把误差加进去有用」。

## 5. 诚实边界

- 3 seed、单任务、单拓扑；判定线 0.40 未动。
- `ω*` 用解析 `Jᵀ`（上界侧信息，与 §6.26 DAgger 同类边界），落地需内部模型。
- 误差项只作用于 `NT_MOTOR_OMEGA*` 的输入突触，**隐藏层从未被误差塑形**；
  即使 `g` 有效也只能说明「读出层可校准」，不能说明「学到了内部模型」。
- 100 轮筛查档单 seed，仅作方向性参考，不入判定。
- 未做权重归一化 / 上限收缩 / 突触缩放等稳态项的对照——这是本结论的直接后续。

## 6. 后续（按性价比）

1. **T2m：误差项 + 稳态**（`satHI` 是唯一可解释变量）：给 `error_gain` 配一条权重归一化/收缩或把 `WEIGHT_MAX` 作用于运动层
   —— 必须先预注册，且这是「规则改动」，**需签字**。
2. **T2n：误差项 + 非平均解码**（wta_k>0 或加权读出），检验「抵消」假设是否就是主因 —— 改动小，也需预注册。
3. **不再**单独扫 `error_gain` 的更高值；`g=5` 已经显示饱和发散。
4. Python 闭环仿真（review 里的 D 项）优先级上升：稳态项的组合要在分钟级迭代里筛，不能再按 5 h/臂的方式试错。
