# T2e · 均衡覆盖采集后的读出上界 预注册（2026-11-14）

> `audit/t2_coverage_report_2026-11-14.md`（T2d，drive-direct 采集）。
> **不是 B2 验收**；阈值零变更（0.40 参考线）。

## 0. 为什么还要再改一次采集

T2d 用 `--drive-direct` 让手臂真的走完任务空间，覆盖确实变宽（θ2 std 1.28、网格 34%），
但**标签分布退化**：手臂 1200 tick 里大部分时间停在目标上（`prox` 因子把期望速度压到 0），
于是样本绝大多数是「ω*≈0」。证据是留出集常数基线 MAE 只有 **0.0548**（T2/T2c 是 **0.3805**）——
两者不可比，T2d 的 `input 0.0433 / hidden 0.1250` 也就不能与 §6.23 的 0.3454 放在一起解读。

因此本实验只改一件事：采集时**每 60 tick 换一个新随机目标**（新开关 `--retarget N`），
让手臂持续追赶、离开「停住」状态，从而得到**均衡的 (θ, target) 覆盖与非退化 ω* 分布**。

## 1. 协议

- 拓扑/参数与 T2d 完全相同：`--preset m2`（1056 / 3500 / 2×250），`avg_conn=8`，`prop_mode=raw`，
  seed=11，`--disable_reward --drive-direct --retarget 60`；
- 采集：20 ep × 1200 tick，stride=10 → 2400 样本，两层各一遍（input 1056 / hidden 3500）；
- 拟合/写回/评估：与 T2d 逐项相同（0–13 训练，ridge α 由训练集 3 折 CV，14–19 留出；
  `--load-readout --readout-layer <layer>` 写回；seed=999、30 ep × 1200 tick 闭环）。

## 2. 判定规则

**前置有效性检查（先于判定）**：

1. 留出集常数基线 MAE **≥ 0.20**（确保标签非退化，与 §6.23 的 0.3805 同量级）；
2. 平均 |ω*| **≥ 0.15**；
3. θ2 std **≥ 0.10** 且 end 位置 8×8 网格覆盖 **≥ 30%**。

三条任一不满足 → **作废**，不得据此判定（说明采集仍退化）。

**判定（与 T2d 同一张表，阈值 0.40）**：

| input | hidden | 判定 |
|---|---|---|
| ≤0.40 | ≤0.40 | 信息与线性可读性都够 → 瓶颈在闭环控制/学习信号；§6.23/§6.24 的「表征不足」归因**撤回** |
| ≤0.40 | >0.40 | hidden 破坏输入信息 → 修拓扑 |
| >0.40 | ≤0.40 | 矛盾组合，先复核 |
| >0.40 | >0.40 | 编码/线性读出族不足 → 换编码或上非线性读出；「架构表达力不足」在均衡采集下**仍成立** |

## 3. 已知风险

- `--retarget 60` 是人为设定的采集节奏，会改变样本的状态密度（越靠近目标的样本越少）。
  这只影响**训练分布**，不影响评估口径（评估仍是 1200 tick 单目标闭环）。
- 手臂起点仍固定 θ=(0,0)；每次重定向都从当前位形出发，覆盖仍不是均匀网格。
- 仍只测线性读出、单 seed。
