# T2d · 覆盖修正后的读出上界 预注册（2026-11-14）

> 运行前落盘。承接：`audit/t2_input_report_2026-11-14.md`（input 上界 0.7923，按预注册判 FAIL）。
> **不是 B2 验收**，不改变 B2 既判 FAIL；**阈值零变更**（仍用 0.40 参考线）。

## 0. 为什么要重做（上个实验暴露的采集缺陷）

T2c 的 input 上界出现**自相矛盾**的一对数字：

- 开环（留出 episode）单步 MAE **0.0258**，而常数基线 0.3805 → 线性可解释度约 **93%**，`CV MSE=0.0124`；
- 闭环 median 却是 **0.7923**（3/30 到达）。

一个开环几乎完美的读出，闭环不该这么差。事后查采集轨迹（`data_b2/t2in/dump_input.csv`）发现根因是**采集分布退化**：

| 量 | 采集（T2/T2b/T2c：随机初始化、不训练） |
|---|---|
| θ1 | [-1.898, 0.024]（单侧） |
| θ2 | [-0.027, 0.023]（**几乎恒为 0**，std 0.01） |
| end_x | [-0.632, 2.0] |
| end_y | [-2.0, 0.047]（单侧） |

未训练网络的运动指令接近常数 → 手臂走到一个固定位形就停住，**20 个 episode 采的是同一条一维窄带**。
于是读出只在「θ2≈0、θ1≤0」的薄片上学到近似，闭环一旦命令 θ2 就进入分布外 → 0.79。

**结论：§6.23/§6.24 用「闭环 median > 0.40」直接归因「表征不足/架构表达力不足」是不成立的**——
至少被「采集分布退化 + 闭环分布漂移」混杂。本实验把采集分布修正后重测上界。

对照验证（已跑，仅作可行性检查）：把采集改为 `--drive-direct`（解析 ω* 驱动，手臂真的走完任务空间）后，
同一 20 ep × stride 10 的覆盖变为 θ1 [-0.781, 0.914]、θ2 [-2.213, 2.391]、end_x [0.334, 2.0]、end_y [-1.695, 1.686]。

## 1. 协议

- 拓扑与参数：`--preset m2`（input 1056 = 1000 位置 + 56 本体感觉，hidden 3500，2×250 motor），
  `avg_conn=8`（§6.24 已关闭扫描），`prop_mode=raw`，seed=11，`--disable_reward`；
- **采集**：加 `--drive-direct`（解析 ω* 驱动臂，学习关闭），20 ep × 1200 tick，stride=10 → 2400 样本；
- **两个源层各跑一遍**：`--dump-layer input`（1056 维）与 `--dump-layer hidden`（3500 维）；
- 拟合：episode 0–13 训练 ridge（α ∈ {0.01,0.1,1,10}，训练集 3 折 CV），14–19 留出；
- 写回：`--load-readout --readout-layer <layer>`，**权重零改动**；
- 评估：seed=999，30 ep × 1200 tick 闭环，同一 median distance ratio；
- 必须报告：两层的 median/到达/单步 MAE/常数基线/α/CV MSE，以及采集覆盖（θ1/θ2/end 范围）。

## 2. 判定规则（阈值不变：median ≤0.40 为 PASS）

| input 上界 | hidden 上界 | 判定 |
|---|---|---|
| ≤0.40 | ≤0.40 | **信息与线性可读性都够** → 瓶颈在**闭环控制/学习信号**；§6.23/§6.24 的「表征不足」归因**撤回**（M2 仍 FAIL，但根因改写） |
| ≤0.40 | >0.40 | **hidden 破坏了输入里已有的信息** → 修拓扑（直通/残差、换 hidden 编码），不换输入编码 |
| >0.40 | ≤0.40 | 异常组合（非线性信息只在 hidden 侧），记为**矛盾**，先复核数据再下结论 |
| >0.40 | >0.40 | **编码/线性读出族都不够** → 换编码（更高维/更密/时间编码）或上非线性读出；「架构表达力不足」在修正采集后**仍成立** |

- **作废条件**：修正采集后覆盖仍不足（θ2 的 std <0.10，或 end 位置 8×8 网格覆盖率 <30%）→ 本次结果作废，
  需先解决「如何在任务空间内均匀采样」，不得据此判定。
- 本实验只改**采集驱动方式**这一项；判定线、评估目标分布（seed 999）、拓扑、扇入全部不变。

## 3. 已知风险

- `--drive-direct` 采集下手臂走的是**解析控制器的轨迹**，不是网络自己的轨迹；这恰好是上界实验想要的
  （覆盖任务状态空间），但**不能**据此说网络能产生这些轨迹。
- 起点固定为 θ=(0,0)，覆盖仍偏向「从伸展位形出发」的流形；若判定为 PASS 需注明该限制。
- 仍只测**线性**读出、单 seed；非线性与种子方差未做。
