# T2j · 速率码读出（temporal code）预注册（2026-11-14）

> 运行前落盘。承接 §6.29（hidden 非线性只到 0.88–0.90，解码头不成立）与 §6.27/§6.28。
> **不是 B2 验收**；B2 保持停止；**阈值零变更**。

## 0. 问题

目前所有读出（§6.23–§6.29）都用**单 tick 二值发放**做特征。这丢掉了时间维：
`ω*` 是「往哪转」的瞬时命令，但单 tick 码对速率/历史不敏感，且 §6.28 显示直连时会被平均化抵消。

本实验换一个**唯一变量**：读出用**指数滑动速率**（rate code）而不是瞬时 0/1：
`r_i(t) = r_i(t−1) + (s_i(t) − r_i(t−1))/τ_rate`，`τ_rate ∈ {20, 100}` tick。

- 若 input/hidden 的**速率读出**闭环达 ≤0.40 → 时间积分**恢复了可读性**，「时序编码」假设成立；
- 若 hidden 明显改善但仍 >0.40 → 部分成立（时间维有用但不够）；
- 若几乎不变 → 问题不在单 tick 二值化，**时序编码这条假设也要放弃**（那就只剩换任务/换规模）。

## 1. 实现（最小改动，权重零改动）

- 核心新增：每神经元速率迹 `rate[]`、`rate_tau`、读出源 `ext_rate`（0=瞬时 0/1 发放，1=速率迹）；
  `net2_set_rate_trace(net, tau)`、`net2_set_ext_rate(net, on)`；
  `rate_tau=0` 时完全不分配/不更新 → 旧路径逐位不变。
- host 新增：`--rate-tau F`、`--dump-values spike|rate`、`--readout-values spike|rate`；
- 速率导出为 **uint8 量化（×255）**，量化误差 ≤1/255≈0.4%，报告里注明；
- 学习规则 / PDc 解码 / 奖励 / 预算 / 评估口径 / §2 阈值：**零改动**。

## 2. 协议（除读出特征外，与 T2e 完全一致）

- 采集：`--preset m2 --disable_reward --drive-direct --retarget 60 --avg-conn 8`，20 ep × 1200 tick，
  stride=10，seed=11；`--rate-tau {20,100}`、`--dump-values rate`；input（1056）与 hidden（3500）各一遍；
- 拟合：episode 0–13 训练 ridge（α ∈ {0.01,0.1,1,10}，训练集 3 折 CV），14–19 留出；
- 闭环：`--load-readout ... --readout-layer <layer> --rate-tau <同值> --readout-values rate`，
  seed=999、30 ep × 1200 tick；
- 必须报告：rate 读出与瞬时读出的**开环 MAE/基线**、**闭环 median**、到达数、密度。

## 3. 判定规则（阈值不变：median ≤0.40 为 PASS）

| 结果 | 判定 |
|---|---|
| 任一层（尤其 hidden）速率读出 **≤0.40** | **时序/速率编码成立** → 记录为可继续的编码方向（后续需在 g=0 训练里验证） |
| hidden 从 1.12 降到 **≤0.80** 但仍 >0.40 | **部分成立**：时间维带来实质改善，但线性读出仍不足 |
| 变化 **<10%**（相对瞬时读数） | **不成立**：单 tick 二值化不是瓶颈 → 该拓扑在 g=0 下不可行，转任务/规模层面 |

- **复现前提**：τ→（瞬时）臂必须复现 T2e 的 input 0.5637 ±0.02、hidden 1.1180 ±0.05（同采集同划分），
  否则本次比对作废。
- τ=20 与 τ=100 只作两个预先声明的取值，不做网格搜索；取更优者作结论依据。

## 4. 已知风险

- 速率迹会让 hidden 的「慢变量」更平滑，可能**显著提升可读性**——但这只是**开环拟合 + 线性闭环读出**，
  与「SNN 自己学得出来」仍有距离（§6.26 的边界同样适用）。
- uint8 量化对极低发放率（<0.004）会截断为 0；报告里给出密度与「非零列数」。
- 单 seed；不做 DAgger；结论限该拓扑与这两个 τ。
