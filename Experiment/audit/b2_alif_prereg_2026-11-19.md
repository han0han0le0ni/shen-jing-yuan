## 0. 依据

### 0.1 为什么是 ALIF

| 事实 | 出处 |
|---|---|
| e-prop 的原始实现与硬件实现都用 **ALIF**（自适应阈值 `A=v_th+βa`、`a_{t+1}=ρa_t+z_t`），纯 LIF 是简化版 | Bellec et al., *Nat. Commun.* 2020；Front. Neurosci. 2022（e-prop on SpiNNaker2）Eq.3-5 |
| 本仓库神经元是**纯 LIF**：`spike_threshold` 固定（仅可选静态异质化），**无适应电流** | `benchmark2_core.c:929`（阈值判定）；`net2_init` 只有 `SPIKE_THRESHOLD` + hetero |
| 静态异质化对本任务无通路（`hetero_thresh` 是死参数 D4） | `§6.44` |

### 0.2 假设与可反驳预测

**H5**：右尾方差的一部分来自**神经元没有自限制**——输出靠外部 k-WTA 排序产生，单个神经元可无限高频发放，
"谁赢"对初始条件极度敏感（跨 seed 盆地）。ALIF 提供活动依赖的自抑制，使 winner 更多由输入而非初值决定。

- H5 成立 ⇒ β=4 mV 档在筛查集 ≥3/4 过线，且 `medR` 均值比 R0（0.2414）降 ≥0.05；
- β 生效（放电率显著下降）但 `medR` 不动 ⇒ H5 的"自限制"分支被反驳；
- β 未生效（放电率不变）⇒ **操纵失败**，本臂不构成检验（D5 教训），先修实现。

### 0.3 已排除（本轮不重复）

`lr`（1e-5/3e-5 同区间）、`episodes`（320→640 不涨）、`wta_k=2`（L 臂 1/4）、
`hetero_thresh`（D4 死参数）、结构可塑 11 臂（剂量/时机/选边，全 FAIL）、
循环密度与临界性 3 臂（K=16 / +ρ*=1.20 / +hm-scale 0.5，全 FAIL，§6.47）。

## 1. 实现（两条路径，先 A 后 B）

### A 路径：只改前向动力学（低成本探路）

| 项 | 内容 |
|---|---|
| 新状态 | `Neuron.adapt_a`（double，初值 0） |
| 每 tick | 循环开头 `adapt_a *= rho_a`；发放时 `adapt_a += 1.0` |
| 阈值 | 判定用 `thr = spike_threshold + alif_beta * adapt_a`（**不写回** `spike_threshold`，保住 hetero 语义） |
| 参数 | `--alif-beta`（mV，**默认 0 = 关闭**）、`--alif-tau-a`（tick，默认 100 ⇒ ρ=0.99） |
| e-prop | **不改**（资格迹仍用 `ep_z` 常数代理，`core.c:937`） |
| 预期 | 高发放神经元被压回、winner 更稳；但学习信号与动力学不一致，可能只降不发散 |

### B 路径：完整 ALIF e-prop（仅当 A 路径"操纵生效但无收益"时）

按 Bellec 2020 Eq.8-9 在 `ψ` 中加适应项（`ψ_j^t` 含 `−β·∂a_j/∂v`），即 `ep_L` 传播多一条**适应迹**
（每神经元 `adapt_trace`），使 `dz/dv` 的间接通路进入资格迹。
改动面：`ep_L` 递推（`core.c:1223-1263`）+ 神经元状态 + 重置逻辑；**本轮唯一的高风险改动**。

**硬纪律**：
1. 两路径默认参数都必须让旧路径**逐位不变**（β=0 时禁用一切适应计算），同命令 20 轮 CSV SHA256 验证（基准 `f7cf46e1621761dd`）；
2. A 路径**不得**触碰 `ep_z` / `ep_L` / `ep_m` / `ep_v` 任何一行；
3. `--alif-beta>0` 时在 stdout 与 meta 打出 `beta / tau_a / rho_a`。

## 2. Gate 0：操纵有效性（先证明它真的在起作用）

**第一道闸门，必须在看 `medR` 之前过**（D5 的教训：生长"跑了但没生效"被误读为空结果）。

| 检查 | 通过条件 |
|---|---|
| 放电率 | 同 seed，`beta=4` 的每 episode 平均发放数比 `beta=0` **下降 ≥10%** |
| 稳定性 | `medD` 不比基线劣化 >0.10（防"降发放=降能力"） |
| 权重饱和 | `wdump_stats.py` 的 `satHi` 仍为 0.00% |

**Gate 0 不过 ⇒ 该档作废（记为操纵失败），换 β 档或修实现；不得把"无变化"当空结果。**

## 6. 风险与预案

| 风险 | 预案 |
|---|---|
| β 过大 ⇒ 神经元静默、`medD` 崩 | Gate 0 的"稳定性"条款直接拦截；β 只允许 4/8 两档，不回补更小档 |
| A 路径（前向改、学习信号不改）造成梯度与动力学失配 | 这正是 A/B 两路径分开的理由；A 失败不等于 ALIF 失败（措辞已预注册） |
| 适应电流使隐含发放率漂移，进而改变 WTA 语义 | 先跑 1 seed 看放电率与 `satHi`，再决定是否上 4 seed（仍属 Gate 0） |
| B 路径破坏旧路径可复现性 | β=0 时禁用全部新计算 + SHA256 逐位验证；`ep_L` 改动必须只在 `beta>0` 分支内 |
| meta 的 JSON 转义缺陷（D6）导致参数无法自动核对 | 本轮先修 D6（写 meta 时把 `\` 转义或用 `/`），或至少用 stdout 的 `v20/alif` 行核对 |

## 7. 明确不做

1. **不改判据阈值**、不按 seed 挑、不在同一 seed 集上二次选择；
2. **不做 E-I 抑制**（改拓扑 + 权重符号，会重定 WTA 语义，另立课题）；
3. **不测** `ih-fan` / `decode-ema`（§6.47 已记为未检验，但优先级低于 ALIF）；
4. 不在 A 路径失败后立刻改 β 档"试到好为止"（β 上限 2 次尝试，写死在 §3）。

## 8. 偏离记录（执行后回填）

| 日期 | 偏离 | 理由 |
|---|---|---|
| 2026-11-19 | 适应只作用于 hidden+motor，输入层豁免 | 输入层是钳位刺激编码层（Step 0 每 tick 直接重写膜电位），施加适应会使其迅速静默、毁掉刺激通路；H5 假设针对的是 k-WTA winner 所在的可整合层 |
| 2026-11-19 | 新增 O(1) `spike_count` 整数计数器 | Gate 0 需要放电率统计；整数自增不改变任何浮点轨迹，beta=0 时 CSV 逐位一致已验证 |
| 2026-11-19 | Gate 0 放电率口径用 spikes/tick 与 spikes/episode 两口径 | 固定 1200 tick 预算下两者等价；均下降 35.7%，结论稳健 |

| 2026-11-19 | B 路径 eps_a 用低通诠释 + beta_eff=beta/10 归一 | 本仓库 e-prop 是常数代理 ψ + 即时前突触迹 + 反馈对齐的简化版，无法逐字套用 Bellec Eq.9 的完整资格迹系统；beta 是 mV 而论文是无量纲，须按阈值间隔 10 mV 归一。首次误用 `eps_a=rho·eps_a+e` 致 medR 崩溃 3.47（放大 100×），修正为低通后恢复 |
| 2026-11-19 | 新增 `--alif-bpath 0|1` 开关 | 把 A 路径（仅前向）与 B 路径（叠加适应资格向量）分成两个可复现臂，默认 0=A；beta=0/bpath=0 旧路径逐位不变 |

> A 路径结果见 `audit/b2_alif_a_path_report_2026-11-19.md`：**Gate 0 PASS（放电率 −35.7%）、Gate 1 FAIL（medR 1/4，均值 0.3033）** ⇒ 判定「前向适应无收益」，满足 B 路径触发条件（§9 第 3 项已确认）。
> B 路径结果见 `audit/b2_alif_b_path_report_2026-11-19.md`：**Gate 0 PASS（两操纵生效）、Gate 1 FAIL（medR 1/4，均值 0.3267，404 劣化 +0.1641）** ⇒ 完整 ALIF e-prop 亦无收益。
