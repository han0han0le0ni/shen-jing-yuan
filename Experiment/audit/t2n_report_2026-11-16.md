# T2n 报告 · 误差项 × 解码方式（PDc vs k-WTA）2×2（2026-11-16）

> 预注册：`audit/t2n_prereg_2026-11-16.md`（运行前落盘）
> 承接：§6.31 T2k（误差单开 → 更差，权重饱和 73–82%）
> **不是 B2 验收**；B2 保持停止；**阈值零变更**（判定线仍 `median ≤ 0.40`）。

## 0. 结论先行

**「PDc 平均抵消」这一假设基本成立。** 把解码从 `Σs·pref/Σs` 换成 k-WTA（K=3）后，
同一误差通道从**有害变成有效**：

- 评测 median 距离 `1.1983 → 0.5595`（**−53%**），到达 `1/60 → 14/60`（1.7% → **23.3%**）；
- 而 PDc 下同一增益是 `1.0966 → 1.2766`（+16%，更差）；
- 逐 seed：`0.6147（1/20）/ 0.1835（12/20）/ 0.9908（1/20）` —— **seed 202 已越过 0.40 判定线**。

按预注册判定：**「部分成立」**（`≤0.80` 且 `Δ ≤ −20%`，但合并值 0.5595 仍 > 0.40）。
这是 T2 系列第一条真正的正向机制证据。

## 1. 协议

- 2×2：解码 {PDc(3), k-WTA(0,K=3)} × `error_gain` {0, 1}；seed 101/202/303；320 ep + 末 20 轮冻结评测（每臂 60 评测轮）
- A/B（PDc 两臂）**复用 T2k** 的同 seed 同参数 CSV；C/D（WTA 两臂）新跑：
  `--preset m2 --decode-mode wta --wta-k 3 --error-gain {0|1}`（零代码改动，`Mode: ... decode=0` 已核对）
- 解码差异（core L831-834）：`decode_mode=3` **完全跳过 k-WTA**（对全部发放神经元平均）；
  `decode_mode=0` 先按膜电位选 top-3 winner，再对 winner 的 `pref_omega` 平均 —— 无对称抵消

## 3. 判定（按预注册分支）

| 预注册分支 | 是否命中 |
|---|---|
| `M(D) ≤ 0.40` 且到达 ≥ 3/60 → 成立 | ✗（0.5595；但到达 14/60 已满足） |
| `M(D) ≤ 0.80` 且 `Δ_wta ≤ −20%` → 部分成立 | **✓（0.5595；−53%）** |
| `Δ_wta > +10%` 或 `|Δ_wta| < 10%` → 抵消不成立 | ✗ |

→ **判定「部分成立」：PDc 平均抵消是主因之一，但不足以单独解释全部失败。**

## 4. 机制

1. **抵消确实存在且是主因**：PDc 对全部发放神经元按 `pref_omega` 平均，对称偏好把误差推动的方向洗掉，
   于是 `dw` 同号累加只让权重整体膨胀（B 臂 satHI 73–82%），命令不跟误差 → 更差。
   换成 top-3 winner 后，命令由「最强偏好的那撮神经元」决定，误差推动不再被平均掉。
2. **残留的第二个瓶颈是饱和**：D 臂 satHI 仍 22–30%（C 臂只有 7–15%），说明误差项依然在推权重上行，
   只是没推到 PDc 那种程度。这正好给出下一步的**量化目标**：把 satHI 从 22–30% 压到 C 臂水平。
3. **方差不小**：三个 seed 分别 0.61 / 0.18 / 0.99——同一个配置能到 0.18（12/20 到达），也能停在 0.99。
   说明系统处在**临界附近**，单 seed 结论不可用。

## 5. 诚实边界

- 3 seed；合并 median 0.5595 仍 >0.40，**不能写成「达成」**；单 seed 的 0.1835 只作提示。
- `wta_k=3` 是 §6.22 的既有取值，本项**未扫 K**；K 是最直接的后续变量（但属新变量，须预注册）。
- `ω*` 仍用解析 `Jᵀ`（上界侧信息）；隐藏层依然没有被误差塑形。
- **「命令–误差相关性」未测**：host 无逐 tick 的 `ω/ω*/cf_err` 导出，机制结论靠 `satHI` + 闭环指标间接推断。
- 100 轮筛查档与本项无关（本项直接跑满 320 ep）。
