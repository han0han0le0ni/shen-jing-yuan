# T2n · 误差项 × 解码方式（PDc vs k-WTA）2×2 预注册（2026-11-16）

> 运行前落盘。直接承接 §6.31（T2k：`error_gain` 单开 → 更差，`I→M` 权重饱和 73–82%）。
> **不是 B2 验收**；B2 保持停止；**阈值零变更**（判定线仍 `median ≤ 0.40`）。

## 0. 问题：两因素交互

§6.31 的失败同时符合两个假设，必须分开验：

- **H1（抵消）**：解码是 `Σ s·pref / Σ s`（PDc，`decode_mode=3`），对称偏好互相抵消，
  误差信号把单个突触推对了方向，但净命令不跟误差 —— §6.28 的机制猜测。
- **H2（饱和）**：`dw` 每 tick 同号累加，规则里没有稳态项，`I→M` 一律顶到 `WEIGHT_MAX=10`。

`wta_k` 把「平均」换成「选优」：`decode_mode=0` 时先按膜电位选 top-K（K=3）运动神经元，
再对 winner 的 `pref_omega` 取平均 —— 不再有对称抵消。**若 H1 成立，WTA + 误差项应显著好于 PDc + 误差项。**
（`decode_mode=3` 完全跳过 k-WTA，见 core L831-834。）

## 1. 设计：2×2，两个 PDc 臂直接复用 T2k（同 seed / 同轮数 / 同参数）

| 臂 | 解码 | `error_gain` | 数据来源 |
|---|---|---|---|
| **A** | PDc（3） | 0 | **复用** `data_b2/t2k/g0/t2k_g0_s{101,202,303}.csv` |
| **B** | PDc（3） | 1 | **复用** `data_b2/t2k/g1/t2k_g1_s{101,202,303}.csv` |
| **C** | k-WTA（0，K=3） | 0 | 新跑 |
| **D** | k-WTA（0，K=3） | 1 | 新跑 |

- 复用合法性：T2k 的跑法就是 `--preset m2 --error-gain {g} --episodes 320 --eval-episodes 20 --seed {101,202,303}`，
  与 A/B 完全一致（无 `--decode-mode` → 默认 3）；复用可省一半机器时间，且保证 A/B 与 T2k 结论**同源可比**。
- 新臂命令：`--preset m2 --decode-mode wta --wta-k 3 --error-gain {0|1}`（`wta` 落到 `decode_mode=0`，CLI 已支持，**零代码改动**）。
- seed 101/202/303；320 ep + 末 20 轮冻结评测（每臂 60 评测轮）。

## 2. 判定规则（差中差 + 绝对线）

记 `M(臂)` = 该臂 3 seed 合并的评测 median 距离。
已知（T2k）：`M(A)=1.0966`、`M(B)=1.2766`（`Δ_pdc = +16%`，误差项变差）。

| 结果 | 判定 |
|---|---|
| `M(D) ≤ 0.40` 且到达 ≥ 3/60 | **抵消假设成立**（H1 是主因）→ 误差驱动+选优解码可行，进 B2 重设计讨论（需签字） |
| `M(D) ≤ 0.80` 且 `Δ_wta ≤ −20%`（相对 `M(C)`） | **部分成立**：抵消是原因之一，但量不够 |
| `Δ_wta` 与 `Δ_pdc` 同号恶化（`Δ_wta > +10%`） | **抵消不成立**：WTA 与误差项冲突 → 进 T2m（稳态） |
| `|Δ_wta| < 10%` | **抵消不是主因** → 进 T2m（稳态） |

- **必须同时看 C（WTA+g0）**：解码一换基线就变，没有 C 就无法把「解码贡献」与「误差贡献」分开。
- 基线参照：§6.22 事后诊断里 `wta_k=3`（未开误差项）闭环为 1.0189 —— 与 C 同量级才算复现，否则本项作废。
- 单变量纪律：不叠 `novelty_gain`、不改 `cf_lambda`/`lr`/拓扑/轮数。

## 3. 必报诊断

- 每臂：评测 median 距离、评测 median 比值、到达数（x/60）；
- `[wstats] I→M` 的 `mean / satHI / satLO`（**饱和量是区分 H1/H2 的关键**：
  若 D 的 satHI 仍 73–82% 而性能变好 → 抵消确实是主因；若 D 也饱和且不改善 → H2 主导）；
- 训练段 median 比值（看是否第 0 轮就不动，§6.28 的自锁模式）。

**未测（诚实边界）**：本 host 没有逐 tick 的 `ω / ω* / cf_err` 导出，因此**「命令–误差相关性」这一条无法直接给出**；
只能靠 satHI 与闭环指标间接推断。若需要，后续要加一个逐 tick 诊断 dump（属工具项，不改判据）。

## 4. 成本（按 T2k 实测校准）

- 新跑 2 臂 × 3 seed = 6 进程，24 核并行 → 墙钟约 **12–15 min**。
