## 1. 实现（v24，默认 ih_fan=20 / decode_ema=0）

- **ih_fan**：`net2_init_ex` 新增第 10 参 `ih_fan`（`net2_init` 转发 20，Python ctypes 调用不受影响）；
  `core.c` 容量估算 `input_count*20 → *ih_fan`、I→H 连接 `k<20 → k<ih_fan`；不改无放回抽样/去重。
- **decode_ema**：解码后、物理步前对驱动臂的 omega 做一阶低通 `ema += (ω−ema)/τ`；
  **只作用于驱动臂**，`decoded_omega*`（学习/诊断用）与 `cf_err*`（攀爬纤维）仍用原始解码值 ⇒ 学习信号零改动。
- **偏离记录（实现位置）**：预注册 §2 草案写"在 `arm_step` 内实现"，实际放在 `net2_tick` 调用点，
  等效且避免改 `arm_step` 公开语义与 `ArmState` 布局。
- **逐位一致（硬门槛）**：历史基准命令 `--episodes 20 --seed 101 --eprop --eprop-lr 1e-5` 下，
  默认档 CSV SHA256 `E819DA1DA28A…` = 改前基准逐位一致；改前/改后二进制同命令 `1BED1A30A3EE…` 亦一致。
  非空操作：`decode_ema=50` → `19F5602D…`、`ih_fan=60` → `E2BA8DEB…`，三者互异。

## 2. Gate 0：操纵有效性 —— PASS（两个因子都有效）

**decode_ema**：预注册 §2 原拟用 `sd(ω)` 度量，但 trace 的 `om` 字段记录的是 `decoded_omega`（EMA **前**的原始解码命令），
故原始指标看不到平滑（sd 0.2992→0.2999）——**这是观测点问题，不是操纵失败**。
改用臂实际角速度（由 `th1/th2` 差分反推，EMA **后**）：

| 臂 | sd(arm ω1) | sd(arm ω2) |
|---|---|---|
| R0（ema=0） | 0.2991 | 0.2536 |
| **M2（ema=50）** | **0.0243** | **0.0244** |

EMA 把驱动臂角速度方差压低 **≈92%**，操纵强烈生效。

**ih_fan**：I→H 实连边（meta `synapses`）115072（fan=20）→ **156778**（fan=60），+36%，动力学实质改变。

⇒ **Gate 0 PASS**。附：预注册 Gate 0 指标 `sd(ω)` 因观测点在 EMA 前而失效，已如实记录为偏离；
用 EMA 后的臂角速度修正后判定。

## 4. 判定与边界

- **H8（decode-ema）部分支持、幅度不足**：三个 τ 档 Δ 均值全负（−0.017~−0.028），方向与"压低量化噪声"预测一致，
  但都未过 Gate 1，且 τ=50→100 收益回落（过平滑），不存在能达标的 τ。808 medD 破线为基线残留。
- **H9（ih-fan）被部分反驳**：感受野 ×2/×3 给出最大的 Δ 均值（−0.045/−0.038），
  且把最差 seed 808 从 0.425 救到 0.23——但代价是健康 seed 303 从 0.157 劣化到 0.21+，
  **净效果是"尾部救援、头部劣化"，过线数归零**。扩大感受野对健康 seed 有害，H9 的"普遍改善"预测不成立。
  近原点目标（|t|<0.5）在 F1/F2 仍 0/3 到达（medD 1.1 左右），与 11-21 可达域审计一致——fan 未解决折叠困难。
- **两因子合并**：EMA 与 fan 分别触及不同的失败机制（量化噪声 vs 感受野），但单独都不足以过 Gate 1；
  预注册 §3 规定组合臂只在单因子过 Gate 1 后追加，本轮**不跑组合臂**。
- **B2 判据仍不通过**，不宣布通过、不回溯调参。

**边界**：筛查集 4 seed；decode-ema 只测 τ∈{20,50,100}、fan 只测 {40,60}；
Gate 0 的 sd(ω) 指标观测点错误已用 EMA 后角速度修正并记录；未算 bootstrap；EMA 只改驱动不改学习信号（按预注册）。

**影响范围**：仅本新课题；B2 结案（§6.46）、B1 通过、B3 条件、判据阈值一律不变。
