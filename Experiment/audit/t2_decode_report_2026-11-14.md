# T2 · 解码可学性上界：**上界即失败**（0.9314）· 2026-11-14

> 预注册：`audit/t2_decode_prereg_2026-11-14.md`（运行前落盘）。
> 定位：**不是 B2 验收**。B2 已按 §2 失败动作停止（判据 v1.21 §6.22），本节只回答
> 「M2 的失败是学习信号问题，还是表征问题」。**不改变**任何基准判据状态。

## 0. 结论

**表征不足。** 在同一个 5000 神经元拓扑上，把 `hidden→motor` 的读出换成**离线监督学出来的线性读出**
（ridge，α 由训练集 CV 选），闭环 median(distance ratio) 只有 **0.9314**（门槛 ≤0.40）；
单步动作预测 MAE **0.3454**，而「常数基线」（永远预测训练集平均动作）是 **0.3805**——
**线性读出的信息量几乎为零**。

参照链路正常：直接用解析 ω* 驱动臂，median **0.0018**、10/10 到达。所以不是评估链路的问题。

**结论**：M2 的失败不能靠改学习规则（R-STDP / 奖励设计 / lr）救回来——
在随机初始化的 hidden 表征里，本来就没有「该往哪转」的可用线性信息。

## 1. 做了什么

| 步骤 | 内容 |
|---|---|
| 采集 | `--preset m2 --disable_reward --dump-hidden`，20 episode × 1200 tick，每 10 tick 采一次 hidden 3500 维二值发放 + 解析 ω*，共 **2400 样本** |
| 划分 | episode 0–13 训练（168 样本/episode），14–19 测试 |
| 拟合 | ridge 对偶形式，α ∈ {0.01, 0.1, 1, 10} 用训练集 3 折 CV 选 → **α=10**，CV MSE 0.1441 |
| 写回 | β（3500×2，float64）通过新增 `net2_set_ext_readout` 写回核心，替换 motor 层解码，**权重零改动** |
| 评估 | 30 episode × 1200 tick，随机目标（seed 999），闭环 |

## 2. 结果

| 条件 | median ratio | 到达 | 说明 |
|---|---|---|---|
| 参照 B（直接 ω* 驱动） | **0.0018** | 10/10 | 物理与评估链路正常（1 tick 延迟已注明） |
| 上界 A（线性读出，闭环） | **0.9314** | 3/30 | 与 M2 的 0.89–1.23 同级，**没有改善** |

诊断量：留出 episode 单步 `MAE = 0.3454`，常数基线 `0.3805` → 线性可解释方差约 **8%**。

## 3. 为什么（可解释的机制）

`avg_conn=8`：每个 hidden 神经元平均只接 8 条输入。3500 个 hidden 神经元构成的是一个
**极端稀疏的随机投影**，它必然把输入里连续的位置/角度信息打散。任何线性读出都无法从
「每神经元 8 个扇入」的随机特征里恢复光滑的控制函数。

这也解释了 M2 的「学习确实发生但毫无改善」：不是优化不动，是**基函数不够**。

## 4. 下一步（三选一，按性价比排序）

1. **input 层读出上界**（约 1 小时）：把外部读出改接到 input 层（1032 个群体编码神经元）。
   若它 ≤0.40 → 信息在输入里、被 hidden 破坏了 → 修拓扑（提高 fan-in / 加输入→运动直接通路）；
   若它也 >0.40 → 输入编码本身不够 → 换编码（更高维/更密）。
2. **fan-in 扫描**（半天）：`avg_conn` 8 → 16 / 32 / 64，重跑本上界。
   这是最直接的「基函数够不够」的判据，也最可能一次命中。
3. **非线性读出**（半天）：同样数据上做小 MLP。若非线性也不过 0.40，问题在表征而非解码族。

**不建议**：回到 B2 调 lr / shaping / 训练轮数——上界已经说明问题不在学习信号。

## 5. 诚实边界

- 只测**随机初始化**网络（未训练的 hidden）。训练后的表征未测；但 B2 训练本身失败，
  且训练只改突触权重、不改「每神经元 8 扇入」的稀疏结构。
- 只测**线性**读出；非线性上界未做（见 §4.3）。
- 单 tick 二值发放、stride=10；时间积分窗口未扫。
- 参照 B 用了 1 tick 延迟的 ω*，不影响它作为「链路对照」的用途。
- 本节结论只针对**这个**拓扑（1000 输入 / 3500 hidden / 2×250 motor / avg_conn=8）。
