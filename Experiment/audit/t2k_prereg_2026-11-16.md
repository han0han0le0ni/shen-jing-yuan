# T2k · 攀爬纤维误差通道（error-driven / PES 式）预注册（2026-11-16）

> 运行前落盘。承接 `audit/snn_reference_review_2026-11-16.md`（公开项目无一例外用误差/梯度信号，
> 我们只有标量奖励 R-STDP，且误差通道默认关闭）。
> **不是 B2 验收**；B2 保持停止；**阈值零变更**；判定线沿用 `median ≤ 0.40`。

## 0. 问题

`benchmark2_core.c` 已经逐 tick 计算小脑攀爬纤维式误差
`cf_err_j = clamp(ω*_j − ω_j)`（`ω*` = `Jᵀ·u` 方向，`prox` 在 0.15 内收敛到 0），
但 `--preset m2` 把 `error_gain` 设为 **0**，所以这条误差**没有任何通往权重的路径**。
`spec/judgments.md` 全文检索 `error_gain` / `cf_lambda` / 攀爬纤维：**0 次命中** →
§6.22–§6.30 从未测过「往权重里灌误差信号」这一维度。

本实验只换**一个变量**：把 `error_gain` 从 0 抬到正值，其余（拓扑、学习率、PDc、奖励、预算、评估）**全部不变**。

## 1. 实现（零代码改动）

现状核对（2026-11-16 冒烟）：

```
.\benchmark2.exe --preset m2 --error-gain 1.0 --episodes 2 --eval-episodes 0 --seed 101
→ v6: error_gain=1.000 novelty_gain=0.000 cf_lambda=0.00 hetero(tau=0.250 thresh=2.000 tune=0.250)
→ Net: 5056 neurons, 115063 synapses
```

误差项的语义（core L664-701）：只在 `NT_MOTOR_OMEGA1/2` 的**输入突触**上、且**突触前本 tick 发放**时，
`dw += lr · error_gain · e_j · tanh(pref_omega/0.15) · credit`（`credit` = 资格迹）。
与 R-STDP 共用三因子机制，**不是外挂通道**；`error_gain=0` 时逐位回到 §6.22 行为。

## 2. 协议

- 预设：`--preset m2`（其余保持：`cf_lambda=0`、`novelty_gain=0`、`prop_mode=raw`、budget 1200、PDc）
- 臂：`g ∈ {1, 5}`（预先声明的两个取值，**不做网格**）；对照 `g = 0`
- seed：101 / 202 / 303（3 个）
- 每臂：`--episodes 320 --eval-episodes 20`（评测段冻结学习，与 §6.22 同口径）
- 必报：评测段 median、到达数（x/30）、训练段 median 曲线、运动层密度、
  `|Δw|` 累计与权重分位、θ1/θ2 轨迹（**自锁检查**：§6.28 的失败模式是从第 0 轮就不动）

```
# 单臂示例
.\benchmark2.exe --preset m2 --error-gain 1 --episodes 320 --eval-episodes 20 --seed 101 --out runs/t2k_g1_s101.csv
```

## 2.1 成本（2026-11-16 实测）

- 单次 `40 ep + 20 ep 评测` = **56 s** → `320 ep + 20 ep 评测` ≈ **5.3 h / 臂 / seed**。
- 全设计 3 臂 × 3 seed = 9 个进程；本机 24 逻辑核、单进程单线程 → `-Parallel` 九路同跑，墙钟约 **6–8 h**（不是 48 h）。
- 筛查档（先看「动不动」）：`-SeedList "101" -GainList "0,1,5" -Episodes 100` ≈ 1.6 h/臂，三路并行约 **1.8 h**。
- 脚本已就绪：`tools/run_t2k.ps1`（可断点续跑：`--out` CSV 存在即跳过；`-SummaryOnly` 只汇总）。

## 3. 判定规则（阈值不变）

| 结果 | 判定 |
|---|---|
| 任一 `g`：评测 median **≤ 0.40** 且到达 ≥ 3/30 | **误差驱动通道成立** → 记为正向方向；是否迁移到 B2 需**另行签字** |
| median **0.40–0.80** | **部分成立**：误差信号有用但不足以支撑该拓扑 |
| 两档相对 `g=0` 变化 **< 10%** | **不成立**：学习信号也不是瓶颈 → 该拓扑在「局部规则 + 稀疏随机」范式内彻底收口，转梯度范式（T3）或换任务/规模 |

- **复现前提**：`g=0` 三个 seed 必须落在 §6.22 区间 median **0.8903–1.2278**、到达约 5/200 量级，
  否则本次比对作废（只作诊断，不下结论）。
- 单变量纪律：不叠加 `novelty_gain`、不改 `cf_lambda`、不改 `lr`、不改拓扑。

## 4. 已知风险与诚实边界

- `has_error` 阈值是 `1e-6`，误差几乎每 tick 都在 → 更新频率远高于奖励调制（后者靠 `|err|>0.001` 才有）。
  一次性学习率过高可能直接**自锁或爆炸**；因此 `g` 只取两档，且必须报自锁诊断。
- 误差项的方向是 `tanh(pref_omega/0.15)`，即**按运动神经元偏好方向给符号**；
  若 PDc 在解码时对称加权抵消（§6.28 的机制假设），误差信号同样可能被抵消——这是本实验真正要检验的事。
- 误差项只作用于运动层输入突触，**隐藏层依然无法被误差塑形**；因此即使 `g` 有效，
  也只是「读出层可被校准」，不是「隐藏层学到了内部模型」。
- 3 seed、单任务、单拓扑；`ω*` 用的是解析 `Jᵀ`（这是上界侧信息，落地需内部模型，边界与 §6.26 的 DAgger 上界同类）。
