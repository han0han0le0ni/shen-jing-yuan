## 1. 实现（v22，ei_mode=0 默认关闭）

- **最小改法**：新增抑制性中间神经元（IIN）群，接收 hidden 群体发放率驱动，膜电位 `ei_v = decay·ei_v + drive` 累积、超确定性错开阈值 `0.10+0.80·(k+1)/n` 发放后硬重置；发放的 IIN 按**确定性均匀分区**（IIN k → motor 索引 `[k·M/n,(k+1)·M/n)`）向 motor 膜电位注入 `−ei_w` 负电流。
- **不碰硬约束**：不引入负权重（WEIGHT_MIN/clamp 不动）、不改 spike 判定、不改资格迹门控、不改 k-WTA 语义；winner 仍在**被抑制后的膜电位**上由 k-WTA 自主排序产生（网络自主，非手工选边）。
- 参数 `--ei-mode/--ei-n/--ei-w/--ei-tau`，默认 0/0/0/100；meta.json 记录；`ei_n ≤ EI_MAX_N=256` 校验。
- **逐位一致硬门槛**：ei_mode=0 同命令 20ep seed101 CSV SHA256 `E819DA1DA28A…` 与基准逐位一致；ei_mode=1 `0C588161BB1C…` 不同（非空操作）；测试套件 26/31 与基线一致、无回归。

## 2. Gate 0：操纵有效性

- 抑制改变了动力学：ei_mode=1 的 CSV 哈希与 ei_mode=0 不同；四臂 medR 一致朝负方向移动（见 §3），说明负电流注入生效（非 D5 式空操作）。
- medD：多数 seed ≤0.40，808 在各臂 0.39–0.43（基线本就偏高）。无 medD 系统性劣化。
- ⇒ **Gate 0 PASS**（操纵生效）。

## 4. 判定与边界

- **E-I 结论**：侧抑制使 medR **一致朝正确方向移动**（四臂 Δ 均值全负，E0 达 4/4 改善、尾部 707/808 改善最大 −0.0458/−0.0451，符合 H6"尾部改善最大"预测），是此前所有干预（ALIF/结构/密度/工作点/调参）中**第一个展现稳定方向性**的；但**幅度不足**，未过 Gate 1，且剂量（w 0.5→2.0）与规模（n 64→256）加大均不再增益，甚至 808 medD 随剂量恶化（0.43）。
- **H6 部分支持**：抑制的方向性符合预测（尾部改善最大），但不足以把 medR 压到 0.20 门槛内，且尾部 seed 808 的 medD 破线是残留硬伤。判定为"方向获支持、幅度不足"，**B2 判据仍不通过**，不宣布通过、不回溯调参。
- **边界**：筛查集 4 seed、单任务单拓扑；IIN 用均匀分区侧抑制（非生理学精确的连接组），ei_tau=100 未扫；剂量/规模各 2–3 档；未算 bootstrap 置信区间；808 的 medD 破线问题在基线即存在，非 E-I 引入。
- **影响范围**：仅本新课题。B2 结案（§6.46）、B1 通过、B3 条件、判据阈值一律不变。

## 5. 下一步（供决策）

E-I 是目前**唯一显示正确方向性**的方向，值得在下一轮（新预注册）尝试：
1. **增强hibit 的选择性/动态**：IIN 按偏好 omega 选择性抑制（而非均匀分区），或抑制强度随 motor 活动动态调整（真正的活动依赖侧抑制）——当前是常数分区，可能太粗糙。
2. **联合 ih-fan / decode-ema**：E-I 改善竞争，加因子改善表征，两个未测因子可叠加验证。
3. **攻 808 尾部**：medD 0.43 破线是另一个独立问题（制动/到达），需单独诊断。
4. 若不再推进，B2 维持结案，转入阶段 0 剩余冻结项 / B3 论证。
