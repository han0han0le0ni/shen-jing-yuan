## 0. 结论先行

**§6.33 的结论站得住，但离判定线还差一截。**

- **K=1**：8 seed 合并 **0.5398**，逐 seed `0.649/0.375/0.841/0.530/0.447/0.530/0.370/0.604`，到达 25/160（15.6%）
- **K=3**：8 seed 合并 **0.5507**，逐 seed `0.615/0.183/0.991/0.384/0.459/0.730/0.391/0.697`，到达 27/160（16.9%）
- 判据：**「部分成立」并确认稳定**（合并 ≤0.80，且 **7/8** seed 各自 ≤0.80）；**「成立」未达**（≤0.40 只有 2/8 与 3/8）
- 两个条件几乎重合（0.5398 vs 0.5507，差 2%）→ **K=1 与 K=3 等效**这一结论在 8 seed 上复现

## 1. 结果

| 条件 | 合并 median | 逐 seed（20 轮 median） | 到达 | `satHI`（8 seed 范围） |
|---|---|---|---|---|
| K=1,g=1 | **0.5398** | 0.649 / 0.375 / 0.841 / 0.530 / 0.447 / 0.530 / **0.370** / 0.604 | 25/160 (15.6%) | 12–18%（`mean` 2.8–3.3） |
| K=3,g=1 | **0.5507** | 0.615 / **0.183** / 0.991 / 0.384 / 0.459 / 0.730 / 0.391 / 0.697 | 27/160 (16.9%) | 22–30%（3 seed 观测值） |
| 参照 K=1,g=0 | 1.0760（3 seed） | 1.309 / 0.771 / 1.123 | 1/60 | 6–10% |

- 各条件 8 个 seed 的 `≤0.40` 计数：K=1 → **2/8**（202、707）；K=3 → **3/8**（202、606、707）
- `≤0.80` 计数：两者都是 **7/8**（K=1 只有 303 的 0.841 越界；K=3 只有 303 的 0.991）
- 分布**不是双峰**，是一条宽分布（0.18–0.99）；只有 1 个 seed 卡在 1.0 附近

## 2. 判定（按预注册分支）

## 3. 机制确认与遗留

1. **低饱和这一条在 8 seed 上成立**：K=1 新 seed 的 satHI 3.9k–4.4k（16–18%），仍远低于 PDc+g1 的 73–82%。
   → 「饱和不是残留瓶颈」在更多 seed 上复现，T2m（稳态）维持降级。
2. **0.54 的天花板没有变**：即使 8 seed 合并，两个条件都停在 0.54–0.55。
   与 §6.29 的开环上界（input 线性 0.47 / 非线性 0.40）同一量级 → 仍指向「隐藏层从未被塑形 + 读出只能用输入侧信息」。
3. **方差仍是主要风险**：0.18–0.99 的跨度意味着**任何单次实验都不能下结论**；本项的价值就是把「合并值可信」这一点确立下来。

## 4. 诚实边界

- **`g=0` 未补新 seed**（故意的不对称，见预注册 §1）：因此 8 seed 的「Δ」无法重算，只能与 3 seed 的 1.0760 对照。
- 新 seed 是预先声明的 5 个，未做挑选，但 3 个老 seed 早在 §6.33 之前就已看过结果——本项不是完全的盲测。
- `ω*` 仍为解析 `Jᵀ`（上界侧信息，落地需内部模型）；隐藏层未被塑形；无逐 tick `ω/ω*/cf_err` 导出，「命令–误差相关性」未测。
- 判定线 0.40 与 §2 阈值全程未动；B2 仍未重启。
