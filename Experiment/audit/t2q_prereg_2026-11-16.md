# T2q · 0.54 的责任归属：K=1 闭环分布上的开环单步上界（预注册，2026-11-16）

> 运行前落盘。承接 §6.34（K=1,g=1 8 seed 合并 0.5398、7/8 seed ≤0.80，但 ≤0.40 仅 2/8）。
> **不是 B2 验收**；B2 保持停止；**阈值零变更**。

## 0. 问题

0.54 这个天花板是「**输入表征不够**」还是「**内部解码规则（top-1 winner 的 `pref_omega`）不够**」？
两者对 B2 重设计的含义完全不同：前者要动隐藏层/输入，后者要动解码或学习规则。

已知参照（都在 **drive-direct 开环分布** 上测得）：
- input 层线性 ridge：MAE/基线 = **0.47**（§6.22/T2e）、0.0258 vs 基线 0.3805（§6.24 T2c，drive-direct+retarget）
- 6 维精确状态线性天花板：MAE ≈ 0.0983（§6.24）
- 隐藏层：MAE/基线 1.51–2.28（§6.27，劣于常数基线）

本项换一个分布：**K=1,g=1 训练后的闭环访问分布**（也就是 0.54 那个控制器真正会遇到的 states），
在它上面重做「静态线性读出 ω* ← input 特征」，看单步可解码性。

## 1. 做法（零代码改动，只加一个采集脚本）

1. 训练+采集一次：
   `--preset m2 --decode-mode wta --wta-k 1 --error-gain 1 --episodes 320 --eval-episodes 0 --seed 101 --stride 10 --dump-layer input --dump-hidden <bin>`
   —— dump 的 meta 第 2/3 列就是 `cf_omega1_star / cf_omega2_star`（解析 ω*），第 8 列是 episode。
2. 划分：训练 = ep 280–299（控制器已收敛的末段），测试 = ep 300–319（留出 episode）。
3. ridge（对偶形式，α 由训练集 3 折 CV 选，α∈{1e-2,1e-1,1,10}），报：
   - 测试集 **单步 MAE**、**常数基线 MAE**（训练集均值）、**MAE/基线**、R²；
   - 特征密度（非零列比例）。

## 2. 判定规则

| 结果（测试集 MAE/基线） | 判定 |
|---|---|
| **≤ 0.25**（R² ≥ 0.75） | **表征够用**：input 特征在闭环分布上仍能线性解出 ω* → 0.54 的瓶颈在**内部解码规则/学习**，不是表征 |
| 0.25 – 0.75 | **部分**：闭环分布比开环难，表征有损但仍可用 |
| **≥ 0.75** | **表征不足**：闭环访问到的 states 上 input 特征已线性解码不出 ω* → 需动输入/隐藏层（**B2 重设计方向，需签字**） |

- 前提：同一次运行必须同时报「控制器自己的闭环 median」（本 seed），否则无法把上界与 0.54 对齐。
- 单 seed（101），明确声明；不复用 §6.34 的 8 seed 结论做统计推断，只做机制定位。

## 3. 边界（必须写明）

- 这是**开环单步上界**（给定访问到的 state 预测 ω*），**不是闭环上界**：读出没有反馈进环路，不能直接等于「换成线性读出后能到多少」。
- 采集分布来自**一个**控制器（K=1,g=1,seed 101）；换 seed 分布会变，方差已知很大（§6.34）。
- `ω*` 是解析 `Jᵀ` 侧信息；隐藏层不受益于误差塑形这一点不变。
- 不改阈值、不改判据、不动学习规则本体。
