# T2i · 非线性读出：hidden 只到 0.88–0.90（有限可读，不足以支撑改架构）· 2026-11-14

> 预注册：`audit/t2_nonlinear_prereg_2026-11-14.md`（运行前落盘，含一次运行前修订）。
> 定位：**不是 B2 验收**；B2 保持停止；阈值零变更（本实验用**相对**指标判定）。

## 0. 结论

**非线性帮了 hidden 一点，但远不够。** 在同一批状态、同一 train/test 划分上：

| 集 / 层 | 线性 ridge | RFF-ReLU(512) | MLP(32) | 判定用的最佳值 |
|---|---|---|---|---|
| A / input（2400 样本） | 0.1230（0.47） | 0.1265（0.48） | **0.1044（0.40）** | 0.40 |
| A / hidden（2400） | 0.3994（**1.51**） | 0.2692（1.02） | 0.3165（1.20） | 1.02 |
| B / input（4800，DAgger 聚合） | 0.1312（0.49） | 0.1220（0.45） | **0.1087（0.40）** | 0.40 |
| B / hidden（4800） | 0.3645（**1.20**） | **0.2674（0.88）** | 0.2717（**0.90**） | **0.88** |

（括号内为 `MAE / 常数基线`，与 §6.23–§6.27 同口径；`A/hidden` 的线性 1.51 **精确复现 §6.27**，说明流水线一致。）

1. **hidden 的非线性收益是真的但有限**：线性 1.20 → 非线性 **0.88/0.90**（改善约 25–27%），
   但仍在「常数基线」附近（0.88–0.90 of base），**与 input 的 0.40–0.49 差 2 倍以上**；
2. 按预注册判定（0.50–0.90 区间）：**「有限可读」**——hidden 里有部分信息，但
   **不足以支撑「换可学习非线性解码头」这条修法**；§6.27 的「hidden 结构性丢失信息」**保持**；
3. **输入侧确实还有非线性余量**：input 线性 0.47 → MLP **0.40**（+15%）。这说明「解码头」的方向在
   **输入侧**成立——但 §6.28 已证明把输入直连到运动层会因**驱动平均化**而自锁，
   所以这条余量目前**没有可用的落地路径**。

## 1. 做了什么

- 数据（全部既有，不新跑采集）：A = T2e 均衡采集（`--drive-direct --retarget 60`，2400 样本）；
  B = A + T2f 第 1 轮 DAgger on-policy 数据（4800 样本）；
- 划分与 §6.27 一致（episode 0–13 训练 / 14–19 留出）；标签为解析 ω*；
- 三种读出族（都只训练读出层，不动 SNN）：
  1. 线性 ridge（**α 网格与 §6.23–§6.27 完全一致** {0.01,0.1,1,10}，保证可比）；
  2. RFF-ReLU：`h=relu(XW+b)`，m=512，γ∈{1,3}，α∈{0.1,1,10,100}（训练集子样本 3 折选）；
  3. MLP：`d→32→2`，ReLU，Adam(lr 3e-3, batch 256)，输入**与目标**都标准化，
     早停于训练集内 80/20（按 episode）验证，最多 300 epoch（patience 30）；
- 指标：留出集 `MAE`、常数基线 `MAE_base`、比值。

## 2. 判断的边界（重要）

- **非线性读出无法注入闭环**：核心外部读出只接受 2×d 的线性系数（`--load-readout`），
  RFF/MLP 权重写不回网络 → 本实验**只有开环**。§6.25 已证明「开环好 ≠ 闭环可用」，
  所以 0.88 的含义只能是「非线性也读不出多少信息」，不能反推闭环会怎样。
- 单 seed、单划分、单结构（RFF 512 / MLP 32 单元）。**不能**排除「更大更深的网络可读」；
  但注意：MLP 从 2.12（欠训练）修到 1.20（正常训练）后仍远差于 input，趋势不支持「再大就好」。

## 3. 与预注册的偏离（如实记录）

1. 运行前已修订一次 MLP 配置（64 单元/200 epoch/3 折 → 32 单元/60 epoch/单一 80-20 切分），
   原因是本机只有 numpy、原配置单次拟合 >5 分钟；该修订**在读结果之前**落盘于预注册 §1。
2. 运行中发现两个**本次实验的实现缺陷**并修正后重跑（非预注册偏离，但必须记录）：
   - 首跑 MLP 在 input 上发散到 MAE **629**：标准化对稀疏列除以 `std+1e-6` 导致爆炸
     → 改为 `sd` 下限 0.05 + 截断 ±8；
   - 二跑 MLP 欠训练（hidden 2.12，差于线性）：目标未标准化 + epoch 太少
     → 目标标准化、lr 3e-3、epoch 300 / patience 30。
   - **结构（32 单元、单隐层）与判定线未变**；两次修正都只提升 MLP，方向对「hidden 可读」有利（保守）。
3. 线性基线的 α 网格刻意保持与 §6.23–§6.27 一致（0.01–10）；若把 α 扩到 100，
   hidden 线性还能压到约 1.06（§6.27 的 α 敏感性诊断已记录过），但那会让基线口径漂移，故未采用。

## 4. 对路线的影响

| 既有 | 现在 |
|---|---|
| §6.27「hidden 无边际信息（线性）」 | **成立**；本实验补充：非线性也只有 0.88–0.90，仍不可用 |
| §6.24「换输入编码」 | 保持关闭（input 线性/非线性都够用，0.47/0.40） |
| §6.28「直通/残差」 | 保持关闭（运动层驱动平均化自锁） |
| 「非线性解码头」这条修法 | **不成立**（hidden 侧收益不足） |
| 剩余方向 | **时序/速率编码**（唯一未否掉的假设）；或承认该拓扑在 g=0 下不可行 |

**下一步建议**（按性价比）：
1. **时序/速率编码预注册**（T2，半天）：把「单 tick 二值群体码」换成速率码（滑窗发放率）或
   脉冲时序特征，重跑 T2 的上界（开环）与 §6.28 的直通臂（这一步才能解释「平均化自锁」是否只是编码问题）；
2. **Python 侧闭环仿真**（1–2 天）：重实现输入编码 + 臂物理，才能给非线性读出／时序编码一个**闭环**指标；
   否则所有非线性工作都只能用开环做代理，说服力有限；
3. **不建议**：再调读出族（已到瓶颈）、再调 `direct-fan`、回 B2 调 lr/shaping、上结构可塑。

## 5. 诚实边界

- 只有开环；单 seed；单结构；DAgger 集 B 只含第 1 轮 on-policy 数据。
- 「有限可读」的判定落在 0.88（RFF）与 0.90（MLP）——**正好跨在 0.90 判据线上**，
  故应表述为「**接近不可读的上界**」，而不是「明显可读」。
- 不改学习规则、不改 B2 判据、不写容器、不写 SNC。
