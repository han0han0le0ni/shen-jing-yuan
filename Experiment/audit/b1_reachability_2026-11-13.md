# B1 可达性重估（§1 失败动作执行记录 / v1.12）

> 触发条件：§6.11 结论「该比特在结构、常数符号、自然学习、逐 seed 反选四条路径上都取不到」
> 满足 §6.9 预写的降级分支，故本轮执行 §1 的失败动作并附可达性重估。
> **本文只做分析与决策建议，不改任何判据阈值、不新增实验、不进入 B2。**

---

## 0. 结论

**B1（D=200 正确率 ≥80% + 无迹消融 ≥30pp）在当前架构与当前判据下不可达。**
不可达分三层，每层都有已落盘的证据，不依赖本轮新假设：

1. **信息层**：A→A 这一「命名约定」在结构上没有先验（§6.11 结构探针：连接数 400/400 全等、
   `hidden→outA` 与 `hidden→outB` 权重和相对差 `0.00e+00`）。反馈 `y` 只说「对/错」，
   不含「哪条通路才对」；要把它转成方向，必须先知道「哪个刺激属于 A 类」，
   而这正是要学的答案。
2. **动力学层**：严格对称读出 + 同源反馈使对称性成为 R-STDP 的不变子空间（§6.4），
   host 原口径（平局 0.0）是零梯度不动点（§6.9）。可用的驱动力只剩「平局记为失败 −1」
   这一处已知偏离，它把一个光滑的零梯度问题换成一个**双稳鞍点**问题：`theta=0` 是鞍点，
   落点由初始噪声决定，学习规则本身不提供偏向。
3. **容量层（v1.13 复核后修订）**：即使把那个比特**白送**（每 seed 取 `force_plus` /
   `force_minus` 中较好的一个，等于允许 oracle 选符号），在**现有命名约定判据**下上限也只有
   **50.00%（发现集）/ 45.00%（留出集）**。更关键的是**自然臂**（不强制 theta）在
   **6/10 与 8/10 个 seed 上完全零响应**（tie 100%，无任何类别特异性输出）。
   即：B1 的 80% 门槛不是「差一点调参」，而是**多数 seed 的机制根本没产出可判别的输出**。
   改判据可抬到 55–65%，但仍 <80%，且**对自然臂毫无改善**（见 §2.3 与 §2.5）。

因此「再换一种破缺信号」不再是有依据的路线。三条出路见第 3 节，需要项目层面拍板。
**注意**：初版把主因写成「命名约定不可自学」，复核后应修正为「自然机制在多数 seed 上零响应」；
约定问题是次要的（自然臂从不产生反向映射，反向映射只在强制 theta 时出现）。

## 2. 三层不可达论证

### 2.1 信息层：命名约定没有内部来源

B1 的「正确」定义为 `expected = (stim==0) ? output_A : output_B`。这是一条**人为命名约定**，
不是网络能从数据中发现的结构。内部可用信息只有两类：

- **输入侧**：`sensory_A` / `sensory_B` 哪一群在放电——但把它接到「放大哪条输出通路」上，
  就是把答案写进机制，§6.9 已明确禁止；
- **反馈侧**：`y ∈ {+1, −1}` 只说「刚才赢的通路对不对」。

反馈确实携带 1 bit 关于该约定的信息（「本试次类别 + 谁赢」联合起来就是映射本身），
所以 B1 **不是信息论上无解**。缺的是**把这个 1 bit 变成梯度的那一步**：网络不知道
「本试次属于 A 类」，它只能从 `u` 的符号自行推断类别，而 `u` 的符号相对 A/B 的对应关系
由 `v` 的随机初始符号决定（§6.11 实测：`u_A` 符号在 20 个 seed 上约一半一半）。
因此这 1 bit 在规则内部是**不可观测**的，不是「没学好」。

### 2.2 动力学层：鞍点落点由噪声决定

在「平局记为失败 −1」口径下，`theta` 的更新是
`theta ← theta + η·(y − b)·u`。`y` 对 A/B 两类近似同分布，`u` 随类别翻符号，
故两类贡献在 `theta≈0` 附近**相互抵消**（§6.9 已实测）。一旦偏离 0，正反馈会把它锁定在
某一侧——但**朝着哪一侧偏，取决于第一次随机涨落**，不含任何关于约定的信息。
固定符号也救不了：`theta=+1` 为 35.00%/25.00%，`theta=−1` 为 15.00%/25.00%，
与自然臂 30.00%/20.00% 同量级（§6.11），说明两侧都不天然更好。

### 2.3 容量层：两种口径下的上限，以及零响应 seed（v1.13 复核后重写）

> 初版写「机制容量只有门槛六成、一半 seed 输出无响应（tie 100%）」，
> 复核后发现两处不准确：一是「tie 100%」只对 9 个 both-zero seed 中的 5 个成立，
> 另 4 个是「有类别特异性但方向相反」；二是「容量」随判据口径变化，不能只报一个数。
> 更正后的完整数据如下。

| 口径 | 强制 ±（逐 seed 取优）发现 / 留出 | 自然臂 发现 / 留出 | 自然臂零响应 seed |
|---|---|---|---|
| 命名约定（现判据） | **50.00% / 45.00%** | 30.00% / 20.00% | 6/10、8/10 |
| 一致可判别（出路 B） | **55.00% / 65.00%** | 30.00% / 20.00% | 6/10、8/10 |
| 现判据门槛 | 80% | 80% | — |

三条读数：

1. **两种口径均 <80%** → 「B1 在当前机制下不可达」的结论不变。
2. **改口径只救强制臂**：把 4 个「反向锁定」seed（404/1414/1515/1616）从 0 分救回
   50–100%，使强制臂从 50.00/45.00 抬到 55.00/65.00；但**自然臂分数一模一样**
   （30.00/20.00），说明自然动力学从不产生反向映射，约定问题不是自然臂的主因。
3. **主瓶颈是自然臂零响应**：6/10（发现）与 8/10（留出）个 seed 上，无论 theta 取什么值、
   无论哪种判据口径，都不产生类别特异性输出（两个类别都 tie 100%）。
   这与命名约定无关、与门控符号无关，指向 §6.4/§6.5 已反复出现的
   「对称读出无法自发破缺」这一旧根因。

9 个 both-zero seed 的性质拆分：

| 类别 | seed | 现象 |
|---|---|---|
| 完全无响应（5 个） | 101、707、1010、1111、1717 | 两种符号下两类试次全部 tie |
| 反向 / 部分响应（4 个） | 404、1414、1515、1616 | 某一符号下出现类别特异性输出，但方向与命名约定相反（如 1515 的 `+1` 臂：A→B、B→A，分离度 1.00、正确率 0%） |

## 3. 三条出路与代价

### 出路 A：给输入侧一个真实的 A/B 结构不对称

- 做法：让 `sensory_A` 与 `output_A` 在拓扑上天然更近（或在初始化时给一点确定的通路偏置）。
- 代价：直接违反 §6.4 约束①②③的设计初衷；等于把「A→A」这一答案写进结构，
  与 §6.9 禁止的 `stim` 对齐在本质上是同一件事，只是藏得更深。**不推荐。**
- 若采用，B1 就不再检验「单突触远端信用分配」，而退化成检验一个被预置好方向的回路。

### 出路 B：把判据从「命名约定」改成「一致可判别」（改判据，需签字）

- 做法：正确性定义为「同一类刺激在多次试次上给出**稳定且互不相同**的输出偏好」
  （A→X、B→Y、X≠Y 且跨试次稳定），不再要求 X=output_A。
- 理由：B1 的科学内容是**远端信用分配能否把延迟奖励落到正确的突触上**，
  这与「哪条通路被命名为 A」无关。当前的 80%/30pp 判据把命名约定和信用分配捆在一起，
  使一个纯约定问题污染了机制结论。
- 代价：这是**判据变更**，必须记版本、写明理由与影响范围，并由项目负责人签字；
  历史 30pp 结果需在新口径下重算（数据都在，可复算）。
- 附带好处：新口径下「一致可判别」是可以被内部信号检验的（不依赖命名约定），
  §6.11 卡住的 1 bit 问题随之消失。

### 出路 C：承认 B1 失败并停止该线

- 做法：按 §1 原文执行「停止，转 T1/T2 研究，不得进入 B2」，把 B1 标为
  **在严格对称 + 同源反馈前提下的不可达目标**，资源转向 T2 的解码可学性/前向模型。
- 代价：放弃「单突触远端信用分配」这一核心主张的正面验证；但避免了在已知容量不足的
  机制上继续投入。
- 注意：这不等于放弃该主张，而是承认**当前判据形式**无法验证它。

## 4. 建议（v1.13 复核后修订）

**仍优先走 B，但必须明确：B 单独不足以让 B1 通过。**

- **B 是必要的口径修正**：4/20 个 seed 在强制 theta 下能给出完美的类别特异性映射，
  却因方向与命名约定相反被记 0 分；不改口径，测到的就不是「信用分配能力」而是
  「约定是否被猜中」。
- **但 B 不是充分条件**：改口径后自然臂仍只有 30.00%（发现）/ 20.00%（留出），
  因为 6/10 与 8/10 个 seed 在自然动力学下完全不产生类别特异性输出。
  这是 §6.4/§6.5 的「对称读出无法自发破缺」旧根因，与判据无关。
- 因此正确顺序是：**先定口径（B），再把预算压到零响应 seed 上**（例如检查这些 seed 的
  hidden 表征是否压根不含判别方向），而不是继续在门控/迹/校准层面找新机制。
- A（输入侧结构不对称）仍只作为「必须保留命名约定」时的明确降级方案；C 作为兜底。

初版建议只写了「优先 B」，未交代 B 的收益仅限强制臂，属**结论过强**，此处更正。

## 6. 复算方法

现判据口径下逐 seed 取两符号较优值：

```python
oracle_naming = max(g0(force_plus, seed), g0(force_minus, seed))
```

「一致可判别」口径下按预测分布取正常/反向映射的较优者（`eval_n` 平分到两类，
`g0_pred_a = [tie, A, B]` 为 A 类试次的预测计数）：

```python
normal   = (pred_a[1] + pred_b[2]) / (2 * n_per_class)
inverted = (pred_a[2] + pred_b[1]) / (2 * n_per_class)
score    = max(normal, inverted)
```

数据：`Experiment/data/b1_sign/sign_summary.jsonl`（发现集）、
`Experiment/data/b1_sign/sign_holdout.jsonl`（留出集），可由
`py -3 Experiment/tools/b1_self_supervised.py --suite v111 [--holdout]` 完整重建。
