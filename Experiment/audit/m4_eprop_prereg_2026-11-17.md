## 0. 为什么现在做、且必须先定指标

§6.42 已经证明：现行 R-STDP 造出的是**「目标位置 → 粗偏置指令」的开环映射**
（154/160 评测 episode 距离净降，但 `corr(ω,ω*) = −0.046±0.033`、`corr(Δdist,pred) = 0.114±0.055`）。
因此 **`medD` 已经不能区分"学到了更好的控制"与"粗偏置更准一点"**。
本项若沿用 `medD ≤ 0.40` 作主判据，极可能再次得到"分数微动、机制不明"。
⇒ **主判据改为两个可解释量**，`medD` 降为报告项。这是**研究指标的定义**，不是 B2 判据的放宽。

## 1. 假设与可反驳预测

**H1**：现行失败的原因是**学习信号**（隐藏层拿不到与任务误差相关的逐神经元信号），
不是表达力（§6.23/§6.25）、不是工作点（§6.38）、不是学习增益（§6.39）、不是后期破坏（§6.42）。

**可反驳预测（预注册）**：若 e-prop 生效，则
- `corr(ω,ω*)` 应从 **≈0（−0.046±0.033）** 升到**持续正值**；
- `corr(Δdist, pred)` 应从 **0.114** 明显上升（逐 tick 出现方向性）；
- 且这两项在**训练全程**成立，而非单 episode 峰值（§6.41 的教训）。

## 2. 实现规格（改什么、怎么改、怎么回退）

| 项 | 规格 |
|---|---|
| 开关 | 新增 `hp.eprop_mode`（默认 **0** = 旧 R-STDP 逐位不变）；`net2_set_param("eprop_mode", …)`；host `--eprop` |
| 学习信号 | **symmetric**：`L_j = Σ_k W_{j→k} · err_k`，其中 `k` 为运动层神经元（ω1/ω2 两群），`W_{j→k}` 用**真实输出权重**（不用随机 B） |
| 任务误差 `err_k` | `e_k = clamp(ω*_k − ω_k, ±1)`（**原始误差**，不用去均值的 `cf_err`；理由：e-prop 需要的是任务误差，§6.31 的 EMA 差分是另一套机制） |
| 输出层 | `L_k = e_k`（输出单元的伪导数并入下面 z） |
| 伪导数 | `z_j = α·max(0, 1 − |v_j(t) − θ_j| / (θ_j − v_rest))`（Bellec 2019 的分段线性式），`α` 预注册 **0.3**；不等同于 §6.42 的代理梯度 |
| 资格迹 | 复用现有 per-synapse `eligibility_trace`：`ē_ij ← λ·ē_ij + pre_spike_i`（λ 沿用 `tau_trace`），
权重更新 `Δw_ij = lr · L_post · z_post · ē_ij`（**替换**现有 STDP/误差通道；不叠加） |
| 更新位点 | 主臂 = **全部通路**（I→H、H→H、H→M、I→M）；消融臂 = 仅 I→M |
| 优化器 | **ADAM**（论文实测 SGD/Momentum 不收敛）；per-synapse `m, v`（各 115k double ≈ 0.9 MB×2，可接受） |
| 学习率 | 预注册**单 seed 校准**：`lr ∈ {3e-4, 1e-3, 3e-3}`（seed 202，80 ep），**按 `corr(ω,ω*)` 选中位最优者**，写死后再跑全部 seed；**不得**在看到 8 seed 结果后改 lr |
| 逐位兼容 | `eprop_mode=0` 时 `--preset m2 --episodes 320 --seed 101` CSV **SHA256 必须仍为 `4CDE0A79…D2232C`**；不通过即回退 |
| 内存/速度 | 新增状态 ≤ 5 MB；预计单步慢 20–40%（e-prop 的梯度矩阵乘） |

**明确不改**：`psp_factor`、`hidden_base_current`、`motor_base_current`、拓扑与初始化、解码（WTA k=1）、
奖励塑形、`error_gain` 语义（该通道在 e-prop 模式下**关闭**）。

## 4. 判定规则（预注册，全程不调整）

### 4.1 主判据（"e-prop 是否带来新能力"）

| 指标 | 门槛 | 依据 |
|---|---|---|
| `corr(ω,ω*)`（**末 20 轮均值**，逐 seed） | **≥ +0.30 且 8/8 seed 同号为正**，其中 **≥6/8 seed ≥ +0.30** | 基线 −0.046±0.033；+0.30 ≈ 10 SD 的跃变 |
| `corr(Δdist, pred)`（同口径） | **≥ 0.40 且 ≥6/8 seed** | 基线 0.114±0.055；0.40 意味着出现真实的逐 tick 方向性 |

### 4.2 报告项（不作判定，但必须全报）

- `medD` / `medR` / 到达率（与基线 8 seed 并列，便于与历史表对齐）；
- 训练后 `I→H / H→H / H→M / I→M` 的 mean/sd/p5/satHi/Gini（`wdump_stats.py --ref`）；
- **隐藏层有效性**：`‖W_{H→M}‖_F / ‖W_{I→M}‖_F`（末轮），与基线对比；
- 逐 episode 的 `corr` 曲线（`corr_curve.py`），用于判断"持续性"而非峰值；
- 权重随机初值敏感性：同 seed 下换 ADAM 的 β2 或 z 的 α 各一次（1 seed，仅记录）。

### 4.3 结论映射（先写死，避免事后解释）

| 观测 | 结论 |
|---|---|
| 两项主判据均达标 | **H1 成立**：瓶颈在学习信号；随即向负责人提请"是否重开 B2"（B2 判据不动，仍需 ≥6/8 `medD≤0.40`） |
| `corr(ω,ω*)` 达标但 `corr(Δdist,pred)` 不达标 | 命令对齐了但未转化为动作收益 ⇒ 瓶颈下移到**解码/执行**（而非学习），转 §6.29/§6.30 一线 |

| e-prop 训练不稳定（权重 NaN/发散 >2/8 seed） | 记录为"实现不可用"，**不得**用调参后结果替代；先修实现再重跑 |

## 5. 已知风险（提前写明，避免事后找理由）

1. **文献不利**：arXiv 2502.09449 显示 e-prop 在真时序任务上仍落后 STBP（PPL +12.1%、PS-MNIST −27.5%），
   即"e-prop ≈ BPTT"只在部分基准成立。若本项失败，**不能**据此说"梯度法不行"，只能说"e-prop 不行"。
2. **本任务的误差不是"监督标签"**：`ω*` 来自 proximal 反馈，本身可能不是可达的最优指令（§6.42 §4 的可能性 1）。
   e-prop 追逐一个不可达的目标时，`corr` 可能升而 `medD` 不降。
3. **ADAM + 全通路更新可能重演 §6.31 的饱和**：必须监控 `satHi`，若 >20% 视为实现异常并记录。
4. **计算成本**：24 次运行 + 实现期 3–5 天；若实现超过 5 天未通过 §2 的逐位兼容，**停止本项**并如实报告。
