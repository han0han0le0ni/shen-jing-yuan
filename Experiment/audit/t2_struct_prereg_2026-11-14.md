# T2g · hidden 侧结构消融 预注册（2026-11-14）

> 运行前落盘。承接：`audit/t2_dagger_report_2026-11-14.md`（input 0.2597 通过、hidden 1.72 发散）。
> **不是 B2 验收**；B2 既判 FAIL 不变；阈值零变更。

## 0. 问题

T2f 已证明 hidden 的信息损失**不是分布问题**（DAgger 加数据反而更差）。但「修拓扑」可以有两种截然不同的做法：

- 若 hidden **没有边际信息**（把 input 和 hidden 一起读，也不会比只读 input 更好）→ 直接做**直通/残差**（input→motor），
  hidden 只作辅助；
- 若 hidden **有互补信息但单独读不出** → 不该断开 hidden，而应做**联合解码**；
- 若 hidden **是有害特征**（一起读反而更差）→ 必须先重构 hidden 的编码方式（去掉慢变量/降共线），再谈直通。

## 1. 数据前提（已验证）

T2e 的 input/hidden dump 来自**同一条确定性轨迹**（`--drive-direct --retarget 60`，seed 11）：
两份 meta 逐位相等（`max|Δmeta| = 0`，2400 样本）。因此可以在这**同一批状态**上做各读出方案的对比较，
不受轨迹差异污染。

## 2. 五个读出方案（同一批状态、同一 train/test 划分、同一 α 网格）

| 代号 | 特征 | 维度 | 闭环可评估 |
|---|---|---:|---|
| A | input 层 | 1056 | 是（已知 0.5637） |
| B | hidden 层 | 3500 | 是（已知 1.1180） |
| C | **input ⊕ hidden 拼接** | 4556 | 是（新增 `--readout-layer both`，核心 `ext_src=2`；神经元数组 input→hidden 相邻，可连续读） |
| D | hidden **随机 1056 列**（其余 β 补 0） | 3500（有效 1056） | 是（维度匹配对照） |
| E | **RFF(input)**：随机余弦特征 3500 维 | 3500 | 否（只报开环） |

- 拟合：episode 0–13 训练 ridge（α ∈ {0.01,0.1,1,10}，训练集 3 折 CV），14–19 留出；
- 闭环：β 写回（权重零改动），seed=999，30 ep × 1200 tick，median distance ratio；
- 所有方案共用 `avg_conn=8`、同拓扑、同协议。

## 3. 判定规则

以 **A（input，0.5637）** 为基准：

1. **C ≈ A**（`|median_C − median_A| ≤ 0.05`）→ **hidden 无边际信息** → **直通/残差（input→motor）是正确修法**；
2. **C 比 A 差 >0.05** → hidden 是**有害特征**（噪声/共线）→ 必须先重构 hidden，不能只加直通；
3. **C 比 A 好 >0.05** → hidden 有**互补信息**、只是不能单独读出 → 改为**联合解码**方向；
4. **D 比 A 差 >0.30** → 不是维度问题，是**内容/结构**问题（同维随机投影仍不可读）；
5. **E（开环）MAE/基线 ≤0.30** 且 hidden 为 1.51 → 「输入 + 随机非线性特征」本身可行，
   问题出在 **hidden 的具体动力学（递归慢变量/共线）**，不是「随机投影不可用」。

以上 1–3 互斥（先判 1），4、5 为独立读法。判定线 0.40 仅作参照，**本实验主判定用 A 的配对差**，
不用绝对线——避免 §6.25 记录过的「绝对线被分布污染」问题。

## 4. 已知风险

- C 的 4556 维里 input 占 23%，若 ridge 正则不均衡，C 可能天然偏向 input 或 hidden；因此**必须**同时报
  各方案的 α 与 CV MSE，并对 C 报告「input 部分与 hidden 部分的权重范数比」。
- D 的列选择是随机的（固定 seed），单次抽样不能代表所有 1056 列子集；只作维度对照，不作强结论。
- E 只做开环（核心无法注入任意非线性特征），不能闭环；因此 E 的结论只用于**机制解读**，不参与主判定。
- 单 seed、线性读出（C 仍是线性）；本实验不改任何 B2 判据。
